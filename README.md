# 오늘도 사랑해

가족에게 마음을 전하고 싶지만 표현을 시작하기 어려운 사람을 위한 프로젝트다. 아이디어와 기획 의도는 사용자 본인의 경험에서 출발했으며, 발전 과정에서 팀원들과 논의했다는 사용자 진술을 기록했다.

**현재 목표는 포트폴리오 완성이다.** 2026-09-22 사용자 결정에 따라 브라우저 데모를 중심으로 하고 안드로이드 앱은 보조 자료로 둔다. Supabase 추가 연결·복구는 보류한다.

**이 README가 프로젝트의 입구이고, [PLAN.md](PLAN.md)가 현재 계획이다.** 작업을 이어갈 때 PLAN의 목표·범위·확인 지점을 읽고, [개인비서용 기록](/Users/b/Documents/개인비서/자료함/프로젝트/오늘도사랑해/README.md)에서 본인 기여·사용자 결정·실제 검증 상태를 대조한다.

**현재 허용된 작업은 폴더·문서 정리다.** 추가 구현·배포·사용자 모집은 대기 중이다. 계획을 현재 기준으로 지정한 것이 모든 단계를 즉시 실행하라는 뜻은 아니다.

현재 저장소에는 기존 Next.js·Supabase 연동 코드와 안드로이드 프로젝트, 서버 연결과 분리한 `/demo` 로컬 초안이 있다. 데모는 브라우저 저장으로 작성·재생·반응을 체험한다. 최종 디자인 승인·공개 배포·실제 사용자 검증은 아직 완료하지 않았다.
