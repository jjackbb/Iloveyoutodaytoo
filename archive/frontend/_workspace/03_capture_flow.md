## 화면 흐름 (크롭 번호 → 내용)

1. **가입** — 카카오/휴대폰/Google/Apple 4버튼, 하단 약관 문구
2-3. **프로필 설정** — "어떻게 불러드릴까요?" 닉네임 + [랜덤 입력] 버튼, 규칙 2줄(2~10자, 특수문자 불가), 하단 [시작하기]
4. **홈(빈)** — 앱바: ♥오늘도 사랑해 + 알림종. empty-hero "아직 연결된 소중한 공간이 없어요 / 우리만의 첫 번째 앨범방을 만들고 소중한 사람들을 초대해 보세요". 하단 [새로운 앨범방 만들기]. 탭 3개
5. **알림 모달** — 카드 시트, 제목 알림 + [전체 선택] + X, 빈: "받을 알림이 없습니다"
6-9. **앨범방 만들기** — 제목 "새 앨범방을 만들어요 / 우리만의 추억 공간에 이름을 붙여주세요". 필드: 앨범방 이름(예: 우리 가족 행복방). 커버 사진: 프리셋 3장 + [직접 올리기] 타일. 직접 올리기 → **커버사진 선택 크롭 모달**(줌 슬라이더, 취소/선택) → 4번째 타일로 추가(− 배지) + 토스트 "앨범방 규격에 맞춰 커버사진을 담았어요 🖼". 이름 입력 시 [앨범방 만들기] 활성화. **관계유형 질문 없음**
10. **앨범방 상세(빈)** — 앱바: ← / 방이름 / 멤버추가(person+) / 검색 / 햄버거. 빈: "아직 추억이 없어요. 아래 마음 표현하기로 첫 번째 추억을 남겨보세요 🌷". 토스트 "앨범방이 만들어졌어요 🎉". 하단 [마음 표현하기]. **탭바 유지**
11. **더보기 드로어**(햄버거) — 갤러리(>, 없으면 "사진이 아직 없어요") / 좋아요 / 별명 설정 / 숨김 / 🚪앨범방 나가기(빨강)
12-21. **마음 표현하기(작성)** — 사진 타일 0/10~ (첫 장에 [대표 사진] 배지, 각 장 × 삭제). "함께 담을 목소리" 카드: 마이크 원버튼 → 녹음 중 00:00 카운트 → 완료 시 재생 파형+시간. 배지: "✕3초 이상 녹음해 주세요"(빨강) → "✓3초 이상 충족 완료"(초록). "문구 선택" textarea(오늘의 마음을 짧게 남겨보세요). 안내 "사진과 음성 녹음을 모두 담아야 표현할 수 있어요". 하단 [♥표현하기] (조건 충족 시 활성)
22-23. **앨범방 피드** — 게시물 카드: 아바타+닉네임+방금 전+⋯ / 사진 그리드(1큰+2작) / 문구 / 음성 재생바(파형+시간) / ♡0 💬0. 하단 [마음 표현하기]
24-25. **게시물 상세** — 앱바 ←/방이름/⋯. 사진 페이저(1/3 배지). 음성 재생바. ♡ 💬 카운트. "댓글 N". 하단 댓글바: 😊이모지(12개 팝오버) + 텍스트 입력(메시지 또는 음성메시지를 남겨보세요) + 🎙 + 전송
26-33. **음성 댓글 남기기** — 🎙 누르면 바텀시트: 마이크 버튼, 3초 배지(빨→초), [취소]/[댓글 등록] → 댓글 목록에 음성 파형 댓글
34-36. **텍스트 댓글** — 입력 후 전송 → 댓글 2 (음성+텍스트 혼합 목록)
37. **홈(카드 1개)** — .album-card: 커버 사진 / 좌상 [초대] 칩 / **우상 ♡ 즐겨찾기 버튼** / 좌하 멤버 아바타 / 아래 방이름 + "멤버 1명 · 게시물 1개 · 방금 전"
38-39. **사서함** — 세그먼트 [받은 마음|보낸 마음]. 칩: 전체·♡·초대·일대일·랜덤. 빈: "아직 받은(보낸) 마음이 없어요". 하단 [🎙 마음 보내기]
40-45. **마음 보내기** — "받는 사람" +추가하기 → **추가하기 시트**: 검색(이름 초성·전화번호), 기본: 나에게/랜덤, 방별: ㅇㅇ(전체)/멤버 개별, [N 확인] → 선택 아바타 표시(토스트 "1명의 대화상대를 지정했습니다"). "메세지 녹음" 마이크 카드. [보내기]
46-47. **사서함(항목)** — 받은/보낸 마음 카드: 아바타, "ㅇㅇ (전체)", 방금 전, 음성 파형 재생바, 우측 ♡
48. **마이** — 프로필 카드(닉네임, "오늘도 사랑해와 함께한 지 N일째", >) / 용량 카드: 음성 저장 용량 250MB/5GB + 가족 앨범 용량 1.2GB/10GB (게이지) / 큰 글자 토글 / 테마 설정 / 구독 관리 / 알림 설정 / 고객 지원: 개인정보 처리방침·고객센터 / 로그아웃(빨강)
49. **내 정보** — 프로필 사진(× 제거 버튼) + 닉네임 + 마스킹 이메일 / 프로필 사진 변경 / 비밀번호 변경 / 계정 탈퇴(빨강)

## 기존 판정에서 뒤집힌 것 (전부 포함으로)

좋아요(홈 카드 즐겨찾기 ♡ + 게시물 ♡) · 댓글(이모지/텍스트/음성) · 사진 업로드(마음 표현하기, 최대 10장, 대표 사진) · 용량 그래프 · 큰 글자 토글 · 랜덤 보내기/필터 · 알림 모달 · 갤러리 · 별명 설정 · 숨김 · 테마 설정 · 구독 관리

## 아직 그대로인 원칙 (구조·안전)

- 잔여데이터 구조(JS 상태기계, 전역 DOM) 금지 — 서버가 매번 읽는다
- 색은 globals.css 토큰(#d50e68 계열), 기본 17px·터치 44px (WCAG AA)
- 데이터 물리 삭제 금지(탈퇴 제외), Supabase 서울, SERVICE_ROLE_KEY 비움
- 소셜 로그인(카카오/구글/애플)·SMS는 외부 등록이 안 끝나 실동작 불가 — UI는 캡처대로 만들되 동작은 가능한 수단(이메일 dev 로그인)으로 연결하고 사실대로 보고

## 구현 순서 (캡처 순서 그대로)

1. 홈 개정(용어·즐겨찾기♡·메타줄) + 앨범방 만들기 개정(관계질문 제거·커버 직접 올리기+크롭)
2. 앨범방 상세(피드) + 마음 표현하기(사진+음성+문구) ← DB: 게시물/미디어 스키마
3. 게시물 상세 + 댓글(이모지·텍스트·음성) ← DB: 댓글/좋아요
4. 사서함 + 마음 보내기(받는 사람 선택) ← 기존 heart_messages 위에
5. 마이 + 내 정보 + 알림 모달 + 더보기(갤러리·별명·숨김)
6. 가입/프로필 화면 (마지막 — 외부 OAuth 의존)
