# 사용성 테스트 진행안 — 선택 반영·남은 확인

기준: [PLAN](../PLAN.md) 4절과 사용자의 2026-09-28 역질문 답변. 실제 참여·화면 관찰·설문 응답은 `NOT_RUN`이다. 이 문서는 진행 전 검토용이며, [관찰 양식](07_사용자테스트_과업과_관찰기록_틀.md)과 [사용 후 설문 초안](20_사용성테스트_설문_초안.md)을 함께 쓴다.

## 확정한 운영 조건

- **화면 버전:** E6 최신 홈·앨범방 화면으로 기술·사용성 테스트를 진행한다. 새 앨범방 아이콘을 누르면 한 방 데모라는 안내창이 나오는 현재 동작을 유지한다.
- **참여자:** 어머니를 포함한 5명이 참여 가능하다는 사용자 진술이다. 1단계 문제 확인 설문 참여자와 겹쳐도 되며, 기존 데모 노출·학습 효과를 참가자별로 기록한다. 실제 5명이 참여했다고 미리 쓰지 않는다.
- **사용 후 설문:** 세 과업이 끝난 뒤 한 번 받는다. 현재 7문항은 초안이며 정확한 문구는 검토가 남았다. 설문 답은 참가자의 자기 보고다.
- **포트폴리오 역할:** 현재 확인된 사용자 선택, 팀 논의, AI 작성·구현만 쓴다. 사용자가 “대부분 내가 한거”라고 밝혔지만 그 진술만으로 팀원별 세부 역할을 임의 배분하지 않는다.

## 미확정: 화면 사용 확인과 설문 매체

사용자는 “몇명은 구글폼, 몇명은 설문지”라고 답했다. 구글폼도 설문지의 한 형태이므로 여기서 말한 설문지가 **종이 설문지**인지, 두 집단이 **실제 화면을 어떻게 사용하고 확인받는지**는 아직 모른다. 참여자 수를 임의 배분하지 않는다. 매체가 달라도 같은 문항·순서·동의 범위를 쓰고, 응답 ID와 제출 시점을 맞춰 기록하는 안은 준비할 수 있다. 종이 답변을 온라인 폼에 옮기는 경우 원본과 입력자의 수정 여부를 구분한다.

화면 공유·대면으로 조작을 보면 과업별 행동과 도움을 관찰할 수 있다. 설문만 받으면 완료·막힘은 자기 보고로만 기록한다. 두 방식을 섞는다면 분모 `N`도 **실제 행동을 관찰한 참가자**와 **설문만 답한 참가자**로 분리한다.

## 세 과업의 참가자 문장·완료 조건 제안 — 사용자 검토 대기

화면을 보여주기 전에는 최근 실제 표현 경험과 평소 방법을 듣는다. 세 과업은 같은 데모 버전·초기 상태로 시작한다. 사적인 마음을 쓰기 부담스럽다면 가상의 짧은 내용으로 대신할 수 있다고 안내한다. 실제 표현과 화면 조작을 결과에서 나눈다.

| ID | 참가자에게 읽을 문장 초안 | 화면 조작 완료 조건 초안 | 별도로 기록할 것 |
|---|---|---|---|
| T1 작성 | “가족 한 명을 떠올리고, 이 앨범방에 마음을 하나 남겨 보세요. 실제 내용이 부담되면 가상의 짧은 내용으로 해도 됩니다.” | 수단을 스스로 선택해 내용 한 개 이상을 담고 저장 성공 후 같은 기록을 확인 | 수단 선택, 도움, 가상 내용 전환, 저장 오류 |
| T2 열람·반응 | “앨범방에 이미 있던 예시 마음을 열어 보고, 마음에 드는 반응을 하나 남겨 보세요.” | 기존 예시를 찾아 열고 읽거나 재생한 뒤 좋아요 또는 댓글 하나를 남김 | 읽기/재생과 좋아요/댓글을 따로 표시, 역할 전환·진행자 도움 |
| T3 다시 보기 | “방금 남긴 본인의 마음을 다시 찾아 보여주세요.” | T1에서 저장한 바로 그 기록을 목록에서 다시 열기 | 경로, 목록 탐색, 다른 기록과 혼동, 도움 |

무도움 완료는 위 조건을 **진행자의 힌트나 대신 조작 없이** 충족하고 행동을 확인했을 때만 센다. 도움 완료·중단·기술 오류·미시도는 따로 적는다. 참여자의 사적 내용을 평가하거나 가족에게 실제 전송·관계 효과를 검증하지 않는다.

## 진행 순서 초안

1. 참여·메모 의사와 사용 조건을 확인한다. 녹음·녹화·직접 인용은 각각 별도 허락이 있어야 한다.
2. 화면을 보여주기 전 평소 표현 방식과 최근 실제 장면을 짧게 듣는다. 1단계 설문에 답한 참가자라면 재질문·데모 사전 노출을 기록한다.
3. T1→T2→T3을 진행한다. 막힌 동안 성급히 힌트를 주지 않고, 도움을 준 시각·내용을 기록한다. 진행자가 상대 역할로 조작하면 참가자 행동과 구분한다.
4. 세 과업 뒤 [사용 후 설문 초안](20_사용성테스트_설문_초안.md)의 검토된 버전을 한 번 받는다. 응답 매체와 관찰 방식은 참가자별로 기록한다.
5. 관찰과 자기 보고를 분리해 정리한다. 반복 막힘이 있으면 사용자와 우선순위를 정한 뒤 수정하고 같은 과업을 재확인한다.
