# 사용성 테스트 진행안 — 자율 체험·구글폼 선택 반영

기준: [PLAN](../PLAN.md) 4절과 사용자의 2026-09-28 역질문 답변 및 후속 선택. 실제 참여·화면 관찰·설문 응답은 `NOT_RUN`이다. 사용자는 데모 배포 주소를 보내 참가자가 스스로 둘러보고 구글폼에 답하는 방식을 선택했다. 이 진행에서는 화면을 실시간으로 보지 않으므로 [관찰 양식](07_사용자테스트_과업과_관찰기록_틀.md)의 무도움 완료 판정을 쓰지 않는다. [구글폼 구성안](24_사용성테스트_구글폼_구성안.md)은 발송 전 준비 자료다.

## 확정한 운영 조건

- **화면 버전:** E6 최신 홈·앨범방 화면으로 기술·사용성 테스트를 진행한다. 새 앨범방 아이콘을 누르면 한 방 데모라는 안내창이 나오는 현재 동작을 유지한다.
- **참여자:** 어머니를 포함한 성인 5명이 참여 가능하다는 사용자 진술이다. 1단계 문제 확인 설문 참여자와 겹쳐도 되며, 기존 데모 노출·학습 효과를 참가자별로 기록한다. 실제 5명이 참여했다고 미리 쓰지 않는다.
- **과업·사용 후 설문:** 데모 링크와 T1~T3 과업을 함께 전달한다. 자율 체험 뒤 승인한 7문항을 구글폼으로 한 번 받는다. 참가자의 조작 여부·완료 여부는 자기 보고로만 확인한다.
- **포트폴리오 역할:** 현재 확인된 사용자 선택, 팀 논의, AI 작성·구현만 쓴다. 사용자가 “대부분 내가 한거”라고 밝혔지만 그 진술만으로 팀원별 세부 역할을 임의 배분하지 않는다.

## 확인된 방식과 완료 목표

사용자의 최신 답변은 **구글 설문폼 한 가지**와 **배포 주소를 전달한 자율 체험**이다. 종이 설문은 계획에서 제외한다. 참가자별 실제 조작을 직접 보거나 화면을 녹화하지 않는다. 구글폼 답은 참가자가 보고한 경험이며, 실제 행동 기록이 아니다.

사용자는 T1~T3을 데모 링크와 함께 보내고, 기존 **5명 실제 관찰** 조건을 **성인 5명의 자율 체험 설문 응답**으로 바꿨다. 이전 계획의 대면·화면 공유 관찰을 이번 실행으로 기록하지 않는다. 실제 5명 응답은 아직 없다.

## 사용자가 선택한 세 과업 문장·완료 조건

세 과업의 문장과 조건은 사용자가 추천안을 선택했다. 참가자에게는 [링크 안내 문안](24_사용성테스트_구글폼_구성안.md)과 함께 보낸다. 사적인 마음을 쓰기 부담스럽다면 가상의 짧은 내용으로 대신할 수 있다. 실제 표현과 화면 조작에 대한 자기 보고를 구분한다.

| ID | 참가자에게 읽을 문장 초안 | 화면 조작 완료 조건 초안 | 별도로 기록할 것 |
|---|---|---|---|
| T1 작성 | “가족 한 명을 떠올리고, 이 앨범방에 마음을 하나 남겨 보세요. 실제 내용이 부담되면 가상의 짧은 내용으로 해도 됩니다.” | 수단을 스스로 선택해 내용 한 개 이상을 담고 저장 성공 후 같은 기록을 확인 | 수단 선택, 도움, 가상 내용 전환, 저장 오류 |
| T2 열람·반응 | “앨범방에 이미 있던 예시 마음을 열어 보고, 마음에 드는 반응을 하나 남겨 보세요.” | 기존 예시를 찾아 열고 읽거나 재생한 뒤 좋아요 또는 댓글 하나를 남김 | 읽기/재생과 좋아요/댓글을 따로 표시, 역할 전환·진행자 도움 |
| T3 다시 보기 | “방금 남긴 본인의 마음을 다시 찾아 보여주세요.” | T1에서 저장한 바로 그 기록을 목록에서 다시 열기 | 경로, 목록 탐색, 다른 기록과 혼동, 도움 |

위 완료 조건은 **참가자에게 요청할 과업의 목표**다. 화면을 보지 않는 이번 방식에서는 해당 조건 충족과 무도움 완료를 검증할 수 없다. 구글폼의 “직접 해 본 것”과 “막힌 곳”은 자기 보고로만 집계한다. 참여자의 사적 내용을 평가하거나 가족에게 실제 전송·관계 효과를 검증하지 않는다.

## 진행 순서 — 발송 전 준비

1. [구글폼 구성안](24_사용성테스트_구글폼_구성안.md)의 안내·활용 동의·7문항을 비공개로 준비한다. 실제 링크·폼 설정·미리보기는 발송 전에 확인한다.
2. 성인 참가자에게 데모 배포 주소와 T1~T3을 함께 전달한다. 실제 가족에게 쓰는 사적인 내용은 요구하지 않는다.
3. 참가자가 각자 둘러본 뒤 구글폼에 한 번 응답한다. 진행자가 조작을 도와주지 않으며 실시간 행동은 관찰하지 않는다.
4. 설문 응답 수, 직접 해 봤다고 **응답한** 행동, 보고된 막힘, 기존 방법과 비교한 의견을 분리해 정리한다. 1단계 참여와 데모 사전 노출은 확인되는 범위에서만 표시한다.
5. 반복해 보고된 막힘이 있으면 기술 문제인지 사용성 문제인지 재현을 시도하고 사용자와 개선 우선순위를 정한다. 수정 뒤 재확인도 실제 수행한 범위만 기록한다.
