# 데모 내부 후기 설문 — 복사·직접 전달 진행안

기준: 사용자의 최신 요청은 **체험 화면 밖에 ‘데모 후기 설문 제출하기’ 버튼을 두고, 데모 안에서 설문에 답하게 하는 것**이다. 답변 전달은 사용자가 추천한 **복사 후 직접 전달**을 선택했다. 즉시 자동 전송은 구현하지 않는다. [1단계 문제 확인용 구글 설문](18_공동작성_인터뷰안_기반_구글폼_프롬프트.md)은 별도다. 앞서 만들었다고 밝힌 [6단계 사용성 구글폼](24_사용성테스트_구글폼_구성안.md)은 이번 전달 경로로 쓰지 않는다.

## 참가자에게 보낼 문안

> ‘오늘도 사랑해’ 데모를 둘러봐 주세요: https://oneuldo-demo.vercel.app/demo
>
> 가능하다면 다음을 해 봐 주세요. 원치 않거나 막히는 행동은 건너뛰셔도 됩니다. 실제 마음을 쓰기 부담스럽다면 가상의 짧은 내용을 쓰셔도 됩니다.
>
> 1. 소중한 존재를 떠올리고 앨범방에 마음을 하나 남겨 보세요.
> 2. 이미 있던 예시 마음을 열고 반응을 하나 남겨 보세요.
> 3. 방금 남긴 본인의 마음을 다시 찾아 보세요.
>
> 체험한 뒤 화면 바깥의 **‘데모 후기 설문 제출하기’**를 누르고, 설문 끝의 **‘설문 답변 복사하기’**를 누르세요. 복사한 답변을 이 대화방에 붙여넣어 보내주세요. 복사만으로는 전달되지 않습니다.

## 화면·데이터 흐름

1. 데모 도구 줄의 후기 버튼은 앱처럼 보이는 `.demo-phone` 바깥에 있다. 녹음 중 누르면 기존 이탈 확인을 따른다.
2. `/demo/feedback`는 별도 페이지이며, [승인된 7문항](20_사용성테스트_설문_초안.md)과 내부 기획용·포트폴리오용 활용 동의를 구분해 보여준다. 이름·연락처·소중한 존재의 실명·사적인 내용을 적지 말라고 안내한다.
3. 버튼은 답변을 클립보드에 복사한다. 복사 실패 시 선택해 직접 복사할 수 있는 답변 칸을 보여준다. 어느 경우에도 **자동 전송·서버 저장·데모 저장소 기록은 하지 않는다.**
4. 참가자가 링크를 받은 대화방으로 실제로 보내야 사용자가 답변을 받는다. 그 대화방의 발신자 정보가 수신자에게 보일 수 있으므로 익명 수집이라고 쓰지 않는다. 포트폴리오에는 허락된 비식별 요약만 사용한다.
5. 실제 받은 답변 수와 내용은 자기 보고로 기록한다. 과업을 직접 관찰하거나 무도움 완료로 판정하지 않는다. 복사 성공 수는 수신 응답 수가 아니다.
