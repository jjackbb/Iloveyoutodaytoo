# 데모 내부 후기 설문 — 복사·직접 전달 진행안

최신 기준(2026-09-28 E20): [공동 작성 구글폼 프롬프트](18_공동작성_인터뷰안_기반_구글폼_프롬프트.md)와 [현장 인터뷰 흐름](09_사전인터뷰_전체흐름_공동작성.md)을 데모 안의 첫 설문으로 옮겼다. **첫 설문 → 데모 체험 → 화면 밖 ‘데모 후기 설문 제출하기’ → 두 답변 함께 복사 → 직접 전달** 순서다. 기존 구글폼 제작 사실은 기록으로 두고 이번 참가자 흐름에서는 쓰지 않는다. 즉시 자동 전송은 구현하지 않는다.

## 참가자에게 보낼 문안

> ‘오늘도 사랑해’ 첫 설문부터 시작해 주세요: https://oneuldo-demo.vercel.app/demo/pre-survey
>
> 첫 설문을 마치면 데모 체험으로 이어집니다. 가능하다면 다음을 해 봐 주세요. 원치 않거나 막히는 행동은 건너뛰셔도 됩니다. 실제 마음을 쓰기 부담스럽다면 가상의 짧은 내용을 쓰셔도 됩니다.
>
> 1. 소중한 존재를 떠올리고 앨범방에 마음을 하나 남겨 보세요.
> 2. 이미 있던 예시 마음을 열고 반응을 하나 남겨 보세요.
> 3. 방금 남긴 본인의 마음을 다시 찾아 보세요.
>
> 체험한 뒤 화면 바깥의 **‘데모 후기 설문 제출하기’**를 누르고, 설문 끝의 **‘첫 설문 + 데모 후기 답변 복사하기’**를 누르세요. 복사한 답변을 이 대화방에 붙여넣어 보내주세요. 복사만으로는 전달되지 않습니다. 두 설문 사이에는 같은 탭을 이용해 주세요.

50대 참여자 1명은 사용자가 직접 인터뷰하고, 동의를 받은 뒤 같은 첫 설문 화면에서 **진행자 입력**을 선택해 답을 옮긴다. 첫 설문을 마친 다음부터 참여자가 데모를 체험한다. 20~30대 대상은 3~5명이며 별도 사전 설문 집단과 데모 집단으로 나누어 세지 않는다.

## 화면·데이터 흐름

1. `/demo/pre-survey`는 참여·내부 기획용 비식별 요약 동의를 먼저 묻는다. 거절하면 경험 질문 없이 끝내고 임시 답변을 지운다. 이어 포트폴리오 요약 활용을 따로 선택하고, 실제 표현·미표현·장면 없음 중 하나에 따라 질문을 보여준다. 출발점 소개는 답변 뒤에만 보인다.
2. 첫 설문 답변은 **현재 탭의 sessionStorage**에 24시간 임시 보관한다. 서버·데모 IndexedDB에는 넣지 않는다. 탭을 닫거나 브라우저가 저장 공간을 지우면 답변이 없어질 수 있다.
3. 데모 도구 줄의 첫 설문·후기 버튼은 앱처럼 보이는 `.demo-phone` 바깥에 있다. 녹음 중 누르면 기존 이탈 확인을 따른다. 첫 설문이 없는 상태에서 후기에 바로 오면 먼저 첫 설문으로 안내한다.
4. `/demo/feedback`는 별도 페이지이며 [승인된 7문항](20_사용성테스트_설문_초안.md)과 후기 활용 동의를 보여준다. 버튼은 첫 설문과 후기 답변을 합쳐 클립보드에 복사한다. 복사 실패 시 직접 복사할 칸을 보여준다. **자동 전송·서버 저장은 하지 않는다.**
5. 참가자가 링크를 받은 대화방으로 실제로 보내야 사용자가 답변을 받는다. 그 대화방의 발신자 정보가 수신자에게 보일 수 있으므로 익명 수집이라고 쓰지 않는다. 포트폴리오에는 허락된 비식별 요약만 사용한다.
6. 실제 받은 답변 수와 내용은 자기 보고로 기록한다. 과업을 직접 관찰하거나 무도움 완료로 판정하지 않는다. 복사 성공 수는 수신 응답 수가 아니다.
