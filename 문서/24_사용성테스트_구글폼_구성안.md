# 사용성 테스트 구글폼 구성안 — 복사용, 미발송

> **이전 방식의 기록.** 사용자는 이후 데모 안에서 7문항을 작성하고 답변을 복사해 직접 전달하는 방법을 선택했다. 현재 진행안은 [25번 문서](25_데모내_후기설문_복사전달_진행안.md)를 따른다. 앞서 만들었다고 밝힌 구글폼은 이번 사용성 테스트 전달 경로로 쓰지 않는다. 1단계 문제 확인용 구글 설문과는 별개다.

사용자가 선택한 방식은 데모 배포 주소를 각 참가자에게 전달해 스스로 둘러보게 한 뒤, **구글 설문폼**으로 한 번 응답받는 것이다. [1단계 문제 확인 폼](18_공동작성_인터뷰안_기반_구글폼_프롬프트.md)과 별도다. 아래 문안과 문항은 [승인된 7문항](20_사용성테스트_설문_초안.md)을 옮긴 것이다. 사용자는 실제 사용성 구글폼을 생성했다고 밝혔다. Codex는 폼 링크·내용·설정을 확인하지 않았다.

## 제목·첫 화면 문안

**제목:** 오늘도 사랑해 데모 사용 경험

**안내 문안:**

> 이 설문은 ‘오늘도 사랑해’ 데모를 둘러본 경험을 묻습니다. 데모 속 인물과 기록은 체험용이며, 작성한 내용은 실제 가족에게 전송되지 않습니다. 답하기 불편한 질문은 건너뛰셔도 됩니다. 이름·연락처·가족 실명·사적인 글·사진·음성은 이 설문에 적거나 올리지 말아 주세요. 데모에서 무엇을 했는지는 화면을 직접 확인하지 않으므로, 답변은 본인의 체험에 대한 설명으로만 정리합니다.

**참여·활용 확인 문항:** 내부 기획용 비식별 요약에 동의하는지 먼저 묻는다. 포트폴리오에 **직접 인용 없이 비식별 요약**을 쓰는 것은 별도 문항으로 묻는다. 동의하지 않은 활용 범위에 응답을 쓰지 않는다. 폼 제작 시 두 동의의 선택지와 거절 뒤 동선을 실제 미리보기에서 확인한다. 녹음·녹화나 직접 인용 허락을 이 문항으로 대신하지 않는다.

## 참가자에게 보낼 안내 — 데모 링크와 과업을 함께 전달

데모 주소: <https://oneuldo-demo.vercel.app/demo>

사용자가 [T1~T3 문장과 목표](23_사용성테스트_진행안_결정반영.md)를 선택했고, **과업을 데모 링크와 함께 보내기로** 했다. 아래는 복사해 보낼 수 있는 문안이다. 실제 발송과 구글폼 링크 기입은 아직 하지 않았다. 참가자는 성인으로 한정한다.

> ‘오늘도 사랑해’ 데모를 둘러봐 주세요: https://oneuldo-demo.vercel.app/demo
>
> 가능하다면 아래 세 가지를 해 봐 주세요. 막히거나 원치 않는 행동은 건너뛰셔도 됩니다. 실제 마음을 쓰기 부담스럽다면 가상의 짧은 내용을 쓰셔도 됩니다.
>
> 1. 가족 한 명을 떠올리고, 앨범방에 마음을 하나 남겨 보세요.
> 2. 이미 있던 예시 마음을 열어 보고, 마음에 드는 반응을 하나 남겨 보세요.
> 3. 방금 남긴 본인의 마음을 다시 찾아 보세요.
>
> 둘러본 뒤 사용성 설문에 한 번 답해 주세요: [생성한 구글폼 주소 입력]
>
> 데모에서 남긴 내용은 실제 가족에게 전송되지 않습니다. 설문에는 이름·연락처·가족 실명·사적인 내용을 적지 말아 주세요.

이 문구를 보냈다는 사실만으로 세 과업의 수행·완료를 확인한 것은 아니다. 참가자가 보낸 설문에서 **스스로 했다고 답한 범위**만 기록한다.

## 사용 후 일곱 문항

| 번호 | 문항 그대로 복사 | 답변 형태 제안 |
|---|---|---|
| 1 | 어떤 기기로 체험하셨나요? | 휴대전화 / 컴퓨터 / 기타. 모델·브라우저는 알면 선택 기입 |
| 2 | 데모에서 직접 해 본 것은 무엇인가요? | 작성 / 예시 열람·재생 / 좋아요·댓글 / 다시 보기 / 아무것도 못 함 / 기타, 복수 선택 |
| 3 | 하려던 일을 하면서 멈추거나 도움을 받은 곳이 있었다면, 그때 무엇을 하려 했나요? | 자유 응답, 없으면 ‘없음’ 가능 |
| 4 | 가장 쉬웠던 부분과 이유는 무엇인가요? | 자유 응답, 건너뛰기 가능 |
| 5 | 가장 부담스럽거나 헷갈린 부분과 이유는 무엇인가요? | 자유 응답, 건너뛰기 가능 |
| 6 | 평소 전화·메시지 등과 비교해 이 데모를 쓰고 싶은 상황, 쓰지 않을 상황이 있나요? | 자유 응답, 건너뛰기 가능 |
| 7 | 화면을 써 본 뒤 생각이 달라진 점이나 빠진 의견이 있나요? | 자유 응답, 건너뛰기 가능 |

질문 2에서 ‘직접 해 봄’을 선택해도 관찰된 과업 완료로 세지 않는다. 질문 3의 ‘도움’은 진행자가 준 도움이라고 단정하지 않는다. 원래 계획의 무도움 완료율 `n/N`은 이번 자율 체험 응답만으로 계산하지 않는다.

## 발송 전 확인

- 성인 참가자에게 데모 링크와 T1~T3을 함께 보낸다. 이번 목표는 **성인 5명의 자율 체험 후 구글폼 응답**이다. 직접 관찰·무도움 완료를 완료 조건으로 쓰지 않는다.
- 실제 폼의 링크·문항·선택지·활용 동의 분기와 이메일 자동 수집·로그인 요구·응답 결과 요약 공개 설정을 미리보기에서 확인한다. 설정을 확인한 기록과 아직 모르는 항목을 나눈다.
- 참여자가 이전 문제 확인 조사에 답했거나 데모를 봤다면 가능한 범위에서 사전 노출을 기록한다. 이름·연락처·사적인 내용을 폼에 요구하지 않는다.
- 발송·응답·분석·재검증은 사용자가 실제로 진행한 뒤 근거를 받아 기록한다.
