# 1단계 사전 인터뷰 — 서면 응답 전환 결정과 근거

기준일: 2026-09-28. 사용자는 **20~30대 성인 후보 3명은 구글 설문 1회**, **어머니 1명은 직접 인터뷰**하기로 선택했다. 세 명에게 문자 후속은 하지 않고 직접 인용도 하지 않는다. [Gemini에 전달할 설문 초안 프롬프트](15_제미나이_구글설문_작성프롬프트.md)를 준비했다. 이후 사용자가 Google Form에 표시된 문항을 공유해 [문안 검토](16_사전서면설문_초안검토.md)를 남겼다. **폼 설정·전송·실제 응답·직접 인터뷰는 아직 확인되지 않았다.** 기존 [현장용 인터뷰 질문](09_사전인터뷰_전체흐름_공동작성.md)과 [현재 PLAN](../PLAN.md)을 바탕으로 방법 변경의 근거를 보존한다.

## 확정한 방법 — 20~30대 3명은 한 번의 서면 응답

시간을 맞추기 어렵다면 온라인 서면 응답이 현실적이다. 실시간 되물음이 없으므로 질문마다 **최근 실제 한 장면 → 그때 한 행동 → 선택 이유 → 쓴 방법의 충분함 또는 미표현 이유 → 편했던 반대 사례**를 스스로 설명할 수 있어야 한다. 기존 질문을 그대로 길게 복사하지 않고, 짧은 서술형 항목으로 나눈다. 그런 장면이 없다는 답과 불편한 항목 건너뛰기도 허용한다. 사용자 출발점 소개는 경험 답변을 다 받은 뒤에만 배치한다.

| 기존 질문의 목적 | 서면으로 옮길 때 확인할 것 | 이유 |
|---|---|---|
| 최근 한 장면 | 실제 있었던 한 번의 상황을 떠올릴 수 있는가; 없었다는 답도 가능한가 | 추상적인 ‘평소’ 평가만 남지 않도록 |
| 그 뒤 행동·이유 | 말·전화·메시지·미표현 중 실제로 무엇을 했는지 자기 말로 적을 수 있는가 | 현장에서 다시 물을 수 없으므로 사건과 해석을 분리 |
| 기존 방법 | 사용한 방법이 충분했는지, 아무 표현도 하지 않았다면 왜 그랬는지 서로 다른 길로 답할 수 있는가 | 쓰지 않은 수단을 가정하지 않도록 |
| 편했던 반대 사례 | 편했던 일이 있었는지, 없다면 없다고 답할 수 있는가 | 문제를 겪지 않은 반례도 보존 |
| 마무리 | 질문이 놓친 경험을 자유롭게 덧붙일 수 있는가 | 후속 메시지 없이도 빠진 맥락을 받을 수 있도록 |

이는 **비동기 서면 응답**이다. 실시간 인터뷰에서 얻는 되물음·표정·맥락을 관찰한 것으로 적지 않는다. 세 명의 답으로 어떤 문제가 얼마나 흔한지 비율을 주장하지 않는다. 응답이 짧거나 모호하면 해석을 보류한다.

## 부모층 후보와 근거의 성격

어머니의 직접 인터뷰는 마음을 **받는 사람**의 관점을 듣는 데 가치가 있다. 동시에 사용자의 아이디어 출발 경험과 직접 연결된 당사자이므로, 별개의 낯선 참여자가 같은 문제를 겪는다는 **독립적인 확인 근거**와 구분한다. 어머니 한 분의 답으로 부모층 전체를 일반화하지 않는다. 어머니에게는 본인에 관한 아이디어 출발점 소개를 그대로 읽을 필요가 없으며, 구체적인 진행은 사용자가 현장용 질문안을 보고 판단한다.

## 인용과 기록의 영향

기존 선택은 **직접 인용할 정확한 문장과 사용처를 보여준 뒤 별도 허락받기**다. 문자 후속이나 다른 재접촉을 하지 않는다면, 세 명의 서면 응답에서 나중에 고른 문장을 직접 인용할 허락을 받을 경로가 없다. 따라서 사용자는 이 서면 응답을 모집·설문 안내에서 허용받은 범위의 **비식별 요약**으로만 포트폴리오에 쓰고, 직접 인용하지 않기로 했다. 어머니와의 직접 인터뷰에서 특정 발언을 인용하려면 기존 선택대로 문장과 사용처를 보여주고 별도 허락받는다. 실제 동의·응답은 아직 없다.

## 다음 작업과 미실시 상태

사용자가 Gemini 원안의 내용은 버리고 [공동 작성 인터뷰 질문](09_사전인터뷰_전체흐름_공동작성.md)을 기준으로 다시 쓰라고 정정해 [현재 Gemini용 프롬프트](18_공동작성_인터뷰안_기반_구글폼_프롬프트.md)를 준비했다. 질문·분기·동의·개인정보 수집 설정을 확인한 다음 후보에게 전달한다. 어머니는 [현장용 질문](09_사전인터뷰_전체흐름_공동작성.md)을 바탕으로 직접 인터뷰한다. 응답 링크는 사용자가 공유했으나 실제 접근·설정·전송·응답 수집·문제 판정은 확인하지 않았다. 6단계의 사용성 테스트는 어머니 포함 5명 참여 가능·구글 설문 병행으로 별도 기록한다.
