# E26. 별도 포트폴리오 가입 화면 시안

- **사용자 직접 선택:** 참가자 흐름 밖의 별도 포트폴리오 미리보기 화면. 샘플 연령 전환 → 14세 미만 보호자 동의 안내 → 화면상 다음 단계까지.
- **구현 위치:** `frontend/src/app/portfolio/signup-preview/`. 데모 전용 주소의 `/portfolio/signup-preview`에서 볼 수 있으며, 기존 참가자용 첫 설문·데모·후기 경로에는 진입 링크를 넣지 않았다. 이 경로는 데모 공용 저장 레이아웃 밖에 둔다.

## 구현

- 실제 생년월일·보호자 이름·연락처 대신 **14세 이상/14세 미만 예시**를 선택한다. 14세 미만 예시는 보호자와 함께 확인하는 안내 화면을 거쳐 다음 이름 화면 예시로 간다. 14세 이상 예시는 안내 화면을 건너뛴다.
- 전환은 브라우저 화면 상태만 바꾼다. 생년월일·보호자 정보 입력, 이 화면 선택값의 서버 전송·저장, 계정 생성은 없다. 각 화면에서 포트폴리오 시안이며 실제 가입·보호자 동의가 진행되지 않는다고 안내한다.
- 카카오·네이버 로그인/회원가입은 표시하거나 연결하지 않는다. Supabase Auth·DB·운영 앱 가입 차단도 바꾸지 않았다.

## 확인 범위

| 확인 | 결과 | 한계 |
|---|---|---|
| 해당 파일 TypeScript·ESLint | PASS | 정적 검사 |
| 키 없는 기존 로컬 데모 서버의 `/portfolio/signup-preview` | HTTP 200 | 첫 화면 응답 확인. 클릭 상호작용·실기기는 미확인 |
| 공개 데모 배포 | PENDING | 이 문서 작성 시점의 상태. 후속 배포 결과를 별도 기록한다 |
| 실제 가입·미성년 보호자 확인 | NOT_RUN | 포트폴리오 UI 범위 밖 |
