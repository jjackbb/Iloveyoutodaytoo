# E21. 대상 Supabase DB와 실제 앱 운영 적용

- **작업 위치:** `.claude/worktrees/db-video-local`, `worktree-db-video-local` 브랜치. 원본 `main`은 합치지 않았다.
- **사용자 결정:** 앞서 보류했던 원격 적용을 이번에는 진행하기로 했다. 대상 프로젝트 ref는 `wdzzianhfnupmfbjqqac`다.
- **코드 기준:** `fabdaca5ff40d05d099dda788c135312df572316`까지 origin에 푸시했다. 새 SQL의 괄호 오류는 이 커밋에서 수정했다.

## 적용한 것

1. 대상 프로젝트로 Supabase MCP의 읽기 전용 OAuth 연결을 완료했다. 이 세션의 도구 목록에는 해당 MCP가 새로 나타나지 않아, 운영 작업은 대상 ref를 명시한 Supabase CLI로 했다. 다른 프로젝트의 MCP는 사용하지 않았다.
2. 적용 전 대상 프로젝트의 `public` 테이블·Auth 사용자·Storage 버킷이 모두 0개임을 확인했다. 로컬 변경문 3개가 원격에서 모두 미적용인 것도 확인했다.
3. 로컬 DB에서 세 번째 변경문을 앞선 두 변경문 위에 거래로 실행하고 되돌리는 과정에서 괄호 오류를 찾아 수정했다. 수정 후 SQL 실행 성공과 되돌림 후 새 컬럼·변경 이력 0개를 확인했다.
4. 대상 DB에 `20260926000000_initial_schema.sql`, `20260928000000_memory_publish.sql`, `20260928000001_memory_expression.sql`을 순서대로 적용했다. 원격 변경 이력에 세 버전이 모두 표시된다. 적용 후 `public` 테이블 24개, Storage 버킷 6개, `pg_cron` 설치를 확인했다. Auth 사용자는 0명이다.
5. 개인정보처리방침 전체의 사람 검토가 아직 없으므로 Supabase Auth의 신규 가입을 **비활성화**했다. 원격 설정 차이에서 가입 허용을 `true → false`로 바꾼 것만 확인했다. 이메일 확인은 원격에서 켜져 있으며, 앱의 가짜 이메일 가입 방식과 맞추는 결정은 실제 가입 개방 전에 별도로 필요하다.
6. Vercel 기존 앱 프로젝트 `jjackbb-projects/iloveyoutodaytoo`의 **Production** Supabase URL·anon key·service role key를 대상 프로젝트 값으로 갱신했다. URL이 대상 ref를 가리키는 것을 비밀 값 출력 없이 확인했다. Preview 설정은 건드리지 않았다.
7. 위 코드 커밋을 기존 앱 프로젝트에 Production 배포했다. 배포 ID `dpl_881QdjYG5wZH4SjPpsK6gqcvc3Vs`, 상태 `READY`, 운영 주소 <https://iloveyoutodaytoo.vercel.app>. Vercel Turbopack 빌드와 TypeScript가 통과했고 22개 정적 페이지를 생성했다.

## 검증 범위와 남은 일

| 항목 | 결과 | 범위 |
|---|---|---|
| 대상·마이그레이션 | PASS | CLI 연결 ref 일치, 세 파일 원격 이력 일치 |
| DB 접근 정책 | PASS(구조) | `public`의 일반·파티션 테이블에 RLS 누락 0개. 새 반응·답글 정책 및 강화된 추억 RPC의 `anon` 실행 불가·`authenticated` 실행 가능 확인 |
| Supabase 보안 조언 | WARN | 오류 0개, `security_definer_function_executable` 경고 67개(anon 31, authenticated 36). 여러 기존 RPC·트리거 함수가 포함돼 있어 일괄 권한 제거는 하지 않았다. 실제 가입 개방 전 함수별 점검이 필요하다 |
| 공개 앱 경로 | PASS(HTTP) | 운영 주소의 `/`와 `/welcome`, `/legal/privacy`, `/demo/pre-survey`가 200. `/start`는 비로그인에서 `/welcome`으로 이동 |
| 로그인 후 새 기능·실기기 | NOT_RUN | Auth 사용자 0명, 신규 가입 비활성화. 실제 계정 흐름·안드로이드 앱·휴대전화 마이크/영상 확인은 하지 않았다 |
| 실제 사용자·법적 문서 | NOT_RUN | 참가자 응답·인터뷰 없음. 개인정보처리방침 전체의 사람 검토 전까지 가입 개방 금지 |
