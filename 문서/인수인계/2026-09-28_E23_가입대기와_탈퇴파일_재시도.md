# E23. 가입 준비 안내와 탈퇴 파일 재시도

- **작업 위치:** `.claude/worktrees/db-video-local`의 `worktree-db-video-local`. 원본 `main`의 별도 변경은 건드리지 않았다.
- **대상:** Supabase `wdzzianhfnupmfbjqqac`, 기존 앱 <https://iloveyoutodaytoo.vercel.app>.
- **사용자 선택:** 운영자·보호책임자·공개 문의 주소·시행일을 실제 값으로 확정할 방향을 골랐다. 값 자체는 아직 받지 않았다. 파일 삭제 실패는 작업표에 남겨 운영자가 재시도하고, 가입을 닫은 동안에는 가입 폼 대신 준비 중 안내와 기존 계정 로그인을 보여준다. 아이디 방식 대신 카카오·네이버·휴대폰 인증번호 중 무엇을 쓸지는 확인 대기다.

## 적용

- `20260928000003_withdraw_storage_jobs.sql`을 운영 DB에 적용했다. 탈퇴 함수가 같은 거래 안에서 본인 소유 프로필 사진, 나만 보던 추억의 첨부, 혼자만 있던 방의 파일을 `storage_deletion_jobs`에 기록한 뒤 계정을 지운다. 실패하거나 앱 요청이 중단돼도 작업표가 남는다.
- 실제 앱의 탈퇴 동작은 계정 삭제 뒤 작업표에서 삭제 대상을 읽어 Storage 삭제를 시도하고, 실제 객체가 없어진 행만 완료 처리한다. 계정 삭제 후 파일이 남을 수 있음을 탈퇴 완료 화면과 개인정보 처리방침에 반영했다. 운영자 절차는 [탈퇴 파일 삭제 재시도](../운영/탈퇴_파일_삭제_재시도.md)에 있다.
- `/signup`은 입력 폼 대신 준비 중 안내·기존 계정 로그인·데모 링크를 보여준다. `/start`·`/login`·앱 안 초대장도 같은 상태를 안내한다. 이전 가입 Server Action은 직접 호출해도 준비 중 응답을 돌린다. Supabase Auth의 신규 가입 차단도 유지했다.
- 코드·DB 변경은 `e5aa13c` (`[APP] 가입 준비 안내와 탈퇴 파일 재시도 경로`)로 커밋·푸시했다. 기존 앱 Production `dpl_Fwp9eB6X7mE51dRkuKQ2QmixuNo3`를 배포했고 `READY`, 운영 주소 연결을 확인했다.

## 가입 개방 전에 남은 것

1. 운영자·보호책임자 실명/표기, 공개 문의 이메일, 시행일 값을 받고 `/my/contact`와 개인정보 처리방침·약관에 반영한다. 지금은 자리표시자가 남아 있으므로 가입을 열 수 없다.
2. 인증 방식 선택 뒤 가입 트리거와 생년월일·만 14세 미만 판별, 개인정보 항목, 콜백·수신 채널을 함께 설계한다. 현행 `handle_new_user`는 첫 가입 시 `birth_date` 메타데이터가 없으면 거부하므로 카카오·네이버·휴대폰을 설정만 켜서는 가입할 수 없다. 네이버는 현행 `auth_provider` 열거형에도 없다. 현재 아이디 계정 0건을 확인한 것은 E22의 시험 정리 시점이며, 이번 작업에서 실제 가입을 열거나 이관하지 않았다.
3. 로그·백업 보존 기간, Vercel 국외 처리 국가·연락처·법적 근거·거부 방법, 작업표 점검 담당·주기를 확정한다. 실제 Android/iOS 촬영·녹음·영상·초대와 참여자 응답은 여전히 미확인이다.
