3. **적용:** `frontend`에서 `supabase link --project-ref wdzzianhfnupmfbjqqac` → `supabase db push --dry-run`으로 두 파일(`20260926000000_initial_schema.sql`, `20260928000000_memory_publish.sql`)만 올라가는지 확인 → `supabase db push`. 옛 `supabase/schema/` 파일은 쓰지 않는다.

6. **실제 흐름 점검:** 성인 가입 → 앨범방 만들기 → 초대 수락 → 추억(사진·영상·목소리) → 나만 보기 표시·공개로 바꾸기 → 삭제. 실기기(안드로이드 앱)에서.
