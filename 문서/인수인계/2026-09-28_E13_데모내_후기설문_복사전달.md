# 2026-09-28 E13 — 데모 내부 후기 설문·복사 전달

- 작업 위치: `worktree-db-video-local`. 원본 `main`에는 다른 세션의 미커밋 작업이 있어 건드리지 않는다.
- 사용자 선택: 데모 체험 화면 **밖**에 ‘데모 후기 설문 제출하기’ 버튼을 둔다. 답변 전달 방식은 별도 서버 자동 전송 대신 **답변 복사 후 직접 전달**로 확정했다. 1단계 문제 확인 구글 설문은 변경 대상이 아니다.

## 구현

- [데모 앱](../../frontend/src/app/demo/demo-app.tsx)의 체험 도구 줄에 후기 버튼을 추가했다. 녹음 중 버튼을 누르면 기존 이탈 확인을 따른다.
- [`/demo/feedback`](../../frontend/src/app/demo/feedback/page.tsx)에 별도 설문 화면을 만들고 [기존 7문항](../20_사용성테스트_설문_초안.md), 내부 기획용/포트폴리오 활용 선택, 클립보드 복사, 복사 실패 시 직접 복사할 답변 칸을 넣었다. 설문 답은 서버·데모 저장소로 보내지 않는다.
- 현재 발송 문안과 응답 수신 기준은 [25번 진행안](../25_데모내_후기설문_복사전달_진행안.md)으로 정리했다. 앞서 만든 사용성 구글폼은 이번 경로에서 쓰지 않으며 이전 기록으로 남긴다.

## 검증과 한계

| 검사 | 결과 | 한계 |
|---|---|
| 변경 파일 ESLint·TypeScript | PASS | 정적 검사 |
| Next.js webpack 운영 빌드 | PASS | `/demo/feedback` 경로 생성 확인. 기본 Turbopack 빌드는 장시간 출력 없어 중단 |
| 격리 Chrome 모바일 | PASS | 버튼이 체험 화면 밖, 설문 7문항, 복사 내용·전송 POST 0건·복사 실패 대체 경로·가로 넘침 확인 |
| 기존 데모 자동 회귀 | **37/37 PASS** | 합성 마이크·격리 브라우저. 실제 기기·사람 결과 아님 |
| 공개 데모 주소의 새 설문 | `NOT_RUN` | 배포와 배포본 확인이 아직 필요 |

복사 완료와 수신 완료는 다르다. 참가자가 대화방에 실제로 보내야 답변으로 센다. 대화방 발신자 정보가 보일 수 있으므로 익명 수집이라고 표현하지 않는다. 자동 전송은 서버 경로·수신 서비스·운영 설정이 필요하지만 이번 선택에서 제외했다.
