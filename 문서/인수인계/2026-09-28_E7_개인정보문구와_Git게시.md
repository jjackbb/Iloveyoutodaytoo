# 2026-09-28 E7. 개인정보 문구 수정과 Git 게시

- **사용자 직접 요청:** 개인정보 처리방침에 남은 옛 관계 유형 표현을 고치고, 다른 현재 문구에도 옛 '가족방'·'가족'이 있으면 각각 '앨범방'·'소중한 존재'로 바꾼 뒤 Claude 인수인계를 읽어 커밋·푸시한다. 후속 정정으로 선택형 관계 유형을 적지 않고 실제 수집하는 자유 입력 호칭만 간단히 적기로 했다. E3·E6의 "법적 문서는 손대지 말 것"은 당시 인수인계이며, 이 후속 요청이 이번 수정의 근거다.
- **반영:** `frontend/src/content/legal/privacy.md` 제2조 3항을 `앨범방 정보: 방 이름, 구성원 간 호칭`으로 바꾸고 수정일을 갱신했다. 새 DB에 선택형 관계 유형 컬럼은 없고 구성원 호칭은 자유 입력이다. 개인정보 처리방침의 다른 `관계방`, 이용약관, 초대·차단·신고 화면, `llms.txt`, 현재 작업 지시·사용자 테스트 양식의 옛 명칭도 `앨범방`으로 고쳤다. 현재 코드의 일반적인 '가족' 대상 설명은 '소중한 존재'로 넓혔다. 과거 의사결정·검사·화면 캡처의 표현과 URL `/demo/rooms/family`는 당시 기록·기술 경로로 보존했다.
- **검사:** 이번 작업 트리에서 lint, TypeScript, webpack 운영 빌드, `git diff --check` 통과. Claude의 E6 배포본 37/37 및 E3 로컬 DB 127/127·앱 화면 13/13은 **이전 검사 기록**이다. 이번에는 브라우저·DB·원격 서비스를 다시 검사하지 않았다.
- **Git 범위:** `worktree-db-video-local` 브랜치에 B~F 및 E2~E6 코드·문서·검사 증거와 이번 법적 초안 문구를 커밋·푸시한다. 원본 `main`의 별도 미커밋 변경은 포함하지 않는다. 정확한 커밋과 원격 일치는 Git 기록으로 확인한다.
- **남은 확인:** 개인정보 처리방침과 이용약관은 초안이다. 사진·영상 등 실제 수집 항목, 가입 정책, 보유·삭제, 사업자와 문의처를 실제 가입 전에 사람이 전체 검토해야 한다. 이 명칭 수정은 법률 검토 완료를 뜻하지 않는다. 원격 Supabase 적용과 기존 앱 서버 배포는 사용자 결정대로 보류 중이고, 실기기·실사용자 확인은 `NOT_RUN`이다.
