# 2026-09-28 E10. 자율 체험·구글폼 방식 선택 반영

## 사용자 직접 선택

E9에서 남긴 세 질문에 사용자가 답했다.

1. 설문은 **구글 설문폼**으로 진행할 예정. 참가자에게 데모 배포 주소를 전달하고 스스로 **둘러보게** 한다.
2. [T1~T3 문장·완료 조건](../23_사용성테스트_진행안_결정반영.md)의 추천안을 선택했다.
3. [사용 후 7문항](../20_사용성테스트_설문_초안.md)의 추천안을 선택했다.

과업 문장을 **링크와 함께 보내라는 뜻인지**는 명시되지 않았다. “둘러보라”와 T1~T3 과업 수행의 안내 시점은 마지막에 질문한다. 참가자 5명의 연령·미성년 포함 여부도 아직 확인되지 않았다.

## 이번에 바꾼 것

- [PLAN](../../PLAN.md)의 6단계 진행·증거·완료 기준을 최신 자율 체험 방식에 맞게 표시했다. 이전 목표인 **5명 실제 관찰**과 현재 **화면을 보지 않는 구글폼 자기 보고**는 충돌하므로 최종 완료 기준 선택을 남겼다.
- [구글폼 복사용 구성안](../24_사용성테스트_구글폼_구성안.md)을 작성했다. 데모 안내, 활용 동의 구분, 승인된 7문항, T1~T3 안내 문장, 발송 전 확인을 한데 모았다. **실제 Google Form 생성·발송·응답은 하지 않았다.**
- [진행안](../23_사용성테스트_진행안_결정반영.md), [설문 문항](../20_사용성테스트_설문_초안.md), [관찰 양식](../07_사용자테스트_과업과_관찰기록_틀.md), [실행판](../19_PLAN_남은작업_실행판.md), [포트폴리오 사례 초안](../22_포트폴리오_사례초안.md)을 자기 보고/직접 관찰의 근거 차이에 맞춰 정리했다.

## 검증과 다음 단계

이 단위는 문서 변경이다. PLAN·README와 문서 28개의 상대 링크에서 누락 0건, `git diff --check` PASS, 새 진행안·폼 구성안의 우발적 일본어/한자 혼입 없음. 실제 구글폼 설정·참여자 기기·체험 여부·7문항 응답은 `NOT_RUN`이다. 기존 E6 자동 검사 37/37과 데모 HTTP 200은 이전 근거다.

남은 사용자 판단은 **과업 문장을 언제 제시할지**, **기존 5명 실제 관찰 완료 조건을 유지할지**, **미성년 참가자가 있는지**다. 사용자가 답하면 폼 문안·완료 기준을 마지막으로 맞추고, 참가자에게 전송하는 일은 사용자의 진행 범위에 따른다. 원격 DB 적용은 계속 보류하고 실제 가입 전 법적 문서 전체의 사람 검토가 필요하다.
