PLAN 남은 선택 6개

확정된 결정을 다시 묻지 않았습니다. 아래는 실제 조사와 테스트를 진행하기 전에 남은 선택입니다. 추천안은 제안이며, 기타에 직접 작성할 수 있습니다.

현재 화면: 홈 캡처 · 앨범방 캡처 · 공개 데모

성인 3명의 문제 확인 설문과 어머니 인터뷰는 사용자 진행 단계입니다. 실제 응답이나 기록이 있으면 답변과 함께 알려주세요. 없는 동안 문제 가설의 참·거짓이나 기능 효과를 확정하지 않습니다.

1. 최신 홈·앨범방 화면을 테스트에 쓸까요?

대표 시안 A는 선택됐지만, 이후 E5·E6의 배치와 카드 변경은 별도 확인이 남았습니다.

2. 홈의 ‘새 앨범방’ 아이콘은 어떻게 둘까요?

데모는 현재 앨범방 한 개만 지원해 아이콘을 누르면 안내창이 뜹니다. 눌러서 새 방을 만들 수 있을 것처럼 보일 수 있습니다.

3. 5명의 화면 사용을 어떤 방식으로 확인할까요?

구글 설문 답만으로는 과업을 실제로 끝냈는지, 도움을 받았는지 관찰할 수 없습니다.

4. 사용성 설문은 언제, 어떤 문항으로 받을까요?

별도 초안은 과업·막힘·평소 방법과의 차이를 묻습니다. 1단계 문제 확인 설문과는 다른 설문입니다.

5. 1단계 설문 참여자와 6단계 테스트 참여자가 겹쳐도 될까요?

5명 참여 가능하다는 계획은 있지만, 성인 설문 후보 3명과 얼마나 겹치는지는 확인되지 않았습니다.

6. 팀원별 역할을 포트폴리오에 어느 수준까지 적을까요?

아이디어·기획 의도가 사용자에게서 출발했고 팀과 논의했다는 진술은 기록돼 있습니다. 팀원별 세부 역할은 현재 자료만으로 확정할 수 없습니다.
