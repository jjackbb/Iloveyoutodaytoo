## 진행률 점검 — 발송·응답·실기기 제외

이 표는 **후기 설문 방식 변경 전** 사용자가 제외한 발송·참가자 응답·실기기 테스트를 뺀 당시 점검 기록이다. 구글폼 생성 완료는 당시 사용자 진술이었으며, 이후 사용성 설문 전달 방식은 데모 내부·복사 전달로 바뀌었다. 아래 단계 수는 작업량이나 검증된 효과의 비율이 아니다.

| 상태 | PLAN 단계 | 판단 근거 |
|---|---|---|
| 현재 범위 완료 | 0 상태 대조, 3 시안 선택, 4 합의한 데모 흐름 구현, 5 자동 기술 검사·데모 배포 | 대조 문서, A안 선택·반영, 데모 기능, E6 당시 자동 검사 37/37과 배포 기록 |

판단 기준: 최근 실제 표현 장면과 망설인 이유, 기존 방법이 충분했던 반례를 먼저 확인한다. 방법 선택의 어려움인지 표현 계기의 부족인지 드러나지 않으면 기능 효과를 단정하지 않는다.

## 2~5단계: 현재 데모의 핵심 흐름과 확인점

1. 소개 → 홈 → 앨범방: 가입 없이 진입한다. 홈의 새 앨범방 아이콘은 현재 한 방만 지원하는 데모에서 안내창을 띄운다. 사용자가 테스트 동안 현재 동작을 유지하기로 선택했다.
2. 앨범방의 `+` → 작성: 손글씨·목소리·사진·영상 중 고른다. 다른 수단으로 옮겨도 초안은 유지된다. 작성 중 녹음 이탈은 확인 후 버리고, 영상 촬영 이탈은 사용자 결정대로 바로 버린다.
3. 저장 → 상세: 저장 성공 후 상세로 이동한다. 실패하면 초안을 남긴다. 목록에서 다시 열어 읽고, 재생·좋아요·댓글을 쓴다. 반응과 본인 기록 수정·삭제·앨범방 편집은 데모 안의 동작이다.
4. 브라우저 저장소: 같은 브라우저에서 다시 볼 수 있다. 실제 상대에게 전송되거나 다른 기기에 동기화되지는 않는다. 역할 전환은 데모 조작이며 실제 가족의 반응 근거가 아니다.
5. 기술 점검의 남은 범위: 실제 휴대전화 브라우저의 마이크·영상 촬영/업로드·터치·글자 확대, 저장 공간 부족·권한 거부·새로고침 복귀. E6 자동 검사를 실기기 검사로 표시하지 않는다.

## 6단계: 진행 전에 사용할 기록 규칙

- 참가자별 확인 가능한 범위의 데모 버전·사용 기기·실제로 전달받은 설문 답변을 기록한다. 화면을 직접 보지 않으므로 과업 결과와 도움은 자기 보고로만 표시한다. 복사 성공은 답변 수신이 아니다.
- 작성(T1), 예시 열람·반응(T2), 자기 기록 다시 찾기(T3)의 문장·목표는 사용자가 선택했다. 링크와 함께 과업을 보낸다.
- 실제 가족 내용을 강요하지 않는다. 가상의 짧은 내용으로 바꾼 결과는 화면 사용으로만 센다. 진행자가 상대 역할로 반응한 것은 실제 상대의 반응으로 세지 않는다.
- 개선은 반복 보고된 막힘을 기술적으로 재현하고 사용자와 우선순위를 정한 뒤 진행한다. 결과 없는 개선 수치·성공담은 쓰지 않는다.
