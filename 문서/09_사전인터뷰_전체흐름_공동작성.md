# 1단계 사전 인터뷰 — 전체 흐름과 공동 작성 워크시트

기준일: 2026-09-25. 이 파일은 질문 내용을 보존한 작업판이며, 한눈에 보고 입력하려면 [HTML 보기](09_사전인터뷰_전체흐름_공동작성.html)를 연다. 질문이 만들어진 과정과 원문은 [기존 진행안](02_사전인터뷰_진행안.md), 왜 이 문제를 확인하는지는 [문제 준비](01_문제확인_준비.md), 단계 조건은 [PLAN](../PLAN.md)에 남아 있다. 사용자가 성인 참여자를 직접 섭외·인터뷰하고 Codex는 자료와 결과 정리를 돕는다. **실제 인터뷰는 아직 하지 않았다.**

## 한눈에 보는 흐름

`참여 안내·건너뛸 권리 → 평소 표현 방식 → 최근 실제 장면 → 그 뒤 행동·당시 상황 → 쓰던 방법의 충분함 → 편했던 반대 사례 → 사용자 출발점 소개 → 빠진 경험·인용 범위 확인`

앞의 **실제 경험**을 듣는 동안 서비스 화면을 보여주거나 쑥스러움·관계 불편함·시간 엇갈림 중 하나를 답으로 먼저 제시하지 않는다. 표현을 미룬 일이 없어도, 기존 전화·메시지만으로 충분해도 그대로 기록한다. 질문은 순서대로 전부 읽는 대본이 아니라 **답에 따라 건너뛰는 지도**다.

| 단계 | 알고 싶은 것 | 지금 쓸 문장·상태 | 답에 따른 진행 |
|---|---|---|---|
| 0. 안내 | 무엇을 위해 듣는지, 메모·건너뛰기·익명 기록에 동의하는지 | 아래 **A**에서 사용자 말투로 작성. 기존 [AI 안내 초안](02_사전인터뷰_진행안.md)은 참고만 | 참여를 원하지 않으면 종료. 녹음·녹화는 별도 동의 전 실시하지 않음 |
| 1. 평소 | 가족에게 마음을 표현하는 방법 | “평소 가족에게 마음을 어떻게 표현하세요?” — **사용자 제안 기반 작업안** | ‘한다/안 한다’ 평가에서 멈추지 않고 최근 한 번으로 이동 |
| 2. 최근 장면 | 실제 표현했거나 전하고 싶었지만 하지 않은 한 번 | 표현했다면 “가장 최근에는 언제 표현하셨나요? 그때 어떻게 하셨어요?” / 표현하지 않는다면 “최근 전하고 싶었지만 전하지 않은 순간이 있었나요?” — **AI 예시·사용자 긍정 반응** | 최근 사례가 없다면 없는 그대로 기록. 가상의 장면을 만들게 하지 않음 |
| 3. 그 뒤 | 실제 행동과 멈춘 순간의 맥락 | 결과가 불분명하면 “그 뒤에는 어떻게 하셨어요?” / 실제 말하려다 멈췄다면 “말하려다 멈춘 그때, 무슨 일이 있었나요?” — **AI 문장·사용자 선택** | 이미 행동·상황을 들었다면 반복하지 않음. 이유는 참여자 말로 듣기 |
| 4. 쓰던 방법 | 기존 방법으로 마음이 충분히 전해졌다고 느끼는지 | **메시지를 실제로 보낸 경우에만:** “지금 그때 보낸 메시지를 돌아보면, 전하고 싶었던 마음을 어느 정도 담았다고 느끼세요?” — **AI 문장·사용자 선택**. 다른 방법·미표현 사례는 아래 **B**에서 작성 | 현재의 회고와 미래에 실제로 후회하는지를 구분. 전화·대면 등 다른 방법에 ‘메시지’ 문구를 강요하지 않음 |
| 5. 반대 사례 | 표현이 어렵지 않았던 최근 순간이 있는지 | “최근 가족에게 마음을 표현하기 편했던 순간이 있다면, 어떤 때였나요?” — **AI 문장·사용자 선택**. 그 이유를 듣는 후속 문장은 아래 **C**에서 작성 | 그런 순간이 없다는 답도 허용. 생일은 답이 막힐 때만 후속 예시로 검토 |
| 6. 출발점 소개 | 인터뷰어가 왜 이 주제를 묻는지 설명 | 어머니와의 표현 경험을 바탕으로 한 [AI 소개 작업안](02_사전인터뷰_진행안.md#아이디어-출발점-소개-순서--사용자-확인)에 사용자 긍정 반응이 있음. **최근 경험을 먼저 듣는 순서**는 사용자 선택 | 아래 **D**에서 정확한 소개 위치·길이를 검토. 후회·추억 동기는 핵심 경험을 다 들은 뒤 설명하는 방향에 동의함 |
| 7. 마무리 | 빠진 경험·반례가 있는지, 기록을 어디까지 써도 되는지 | 아래 **E**에서 사용자 말투로 작성. [AI 마무리 참고안](02_사전인터뷰_진행안.md)은 확정본이 아님 | 포트폴리오 직접 인용은 별도로 범위를 확인. 다음 화면 체험 동의·일정은 별개 |

## 이번에 한 번에 작성할 칸

**A. 시작 안내 — 왜 묻나?** 참여자가 답변의 목적과 선택권을 알고 시작하도록 한다. 제품을 좋게 평가해 달라는 요청으로 들리지 않게 한다. 기존 안내 초안에는 익명 메모, 건너뛸 권리, 화면을 보기 전 대화가 포함되어 있다. 사용자 말투로 짧게 다시 써 본다.

## 진행자 메모와 완료 조건

- 인터뷰 중에는 **실제 상황·행동·참여자 설명**을 먼저 적고, 진행자의 추측은 따로 적는다. ‘쑥스러움’, 관계 불편함, 시간 엇갈림은 사용자의 가설이지 참여자 답이 아니다.
- 실명·연락처·민감한 가족 사연·사진·음성을 이 공유 작업판에 옮기지 않는다. 참여자별 실제 기록은 [기존 진행안의 익명 양식](02_사전인터뷰_진행안.md)을 필요한 범위에서 다듬어 쓴다.
- A~E를 한 번에 채운 뒤 **답을 유도하는 표현, 중복 질문, 조건부 질문의 빠진 갈래, 소개 시점**을 함께 검토한다. 그다음 사용자에게 한 묶음으로 확인받아 현장용 질문안을 만든다. 파일이 생겼다는 사실은 질문지 확정이나 실제 인터뷰 완료가 아니다.
- 인터뷰 두 명의 실제 사례를 들은 뒤 [문제 준비](01_문제확인_준비.md)의 가설과 반례를 대조해 **유지 / 좁힘 / 수정 / 판단 보류**를 결정한다. 긍정 답을 모으는 것이 완료 기준은 아니다.
