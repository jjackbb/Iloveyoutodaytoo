# 데모 공개 배포 — 결정 전 검토 자료 (F 준비)

기준일: 2026-09-26. Claude가 [연속 실행 지시서](12_클로드_연속실행_지시서.md) 3절 F의 **준비**로 작성했다. **배포는 하지 않았다.** 공개 범위는 사용자 승인 뒤에 실행한다.

## 결론 먼저 — 추천

**데모 전용 Vercel 프로젝트를 새로 만들고, 서버 키 없이 배포한다(추천).** 기존 주소 `iloveyoutodaytoo.vercel.app`은 안드로이드 앱이 불러오는 서버다(`capacitor.config.ts`의 `server.url`). 그 프로젝트에서 키를 비우거나 이 브랜치를 올리면 앱까지 영향을 받는다. 별도 프로젝트는 앱과 데모를 서로 끊어 둔다.

## 승인 뒤 실행 순서(준비안)

1. 새 프로젝트를 만들고 루트를 `frontend`로, 환경 변수는 **비워 둔다**(Supabase URL·공개 키·서버 키·GA).
2. 배포 뒤 HTTP 응답 확인과 별개로 실제 브라우저에서 작성→저장→재생→반응→다시 보기를 다시 검사한다. HTTP 200은 동작 증거가 아니다.
3. iPhone Safari·안드로이드 Chrome 실기기에서 녹음·뒤로 가기·새로고침을 확인한다(현재 `NOT_RUN`).
