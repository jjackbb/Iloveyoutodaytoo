# 오늘도 사랑해 — 포트폴리오 사례 초안

상태: **검증 결과 입력 전 초안**. 사용자의 실제 문제 조사·기기 테스트·참가자 체험 응답이 들어오기 전에는 완성 사례로 공개하지 않는다. 현재 사용성 테스트는 자율 체험 뒤 구글폼 자기 보고를 받는 방식이며, 5명 실제 관찰 결과로 바꾸지 않는다. [PLAN](../PLAN.md)과 [남은 작업 실행판](19_PLAN_남은작업_실행판.md)의 증거 경계를 따른다.

## 출발점과 검증할 문제

사용자 본인의 어머니와의 경험에서, 마음이 있어도 표현을 시작하지 못할 수 있다는 문제 가설이 시작됐다. 아이디어와 기획 의도는 사용자에게서 출발했고 발전 과정에서 팀과 논의했다는 사용자 진술이 있다. 이 경험 한 건을 다른 사람에게도 같은 문제가 있다는 증거로 확대하지 않는다.

서비스 대상은 사용자가 가족에서 **소중한 존재**로 넓혔다. 연인·나 자신·반려동물의 기록도 담을 수 있다는 의도다. 이번 문제 확인과 사용성 테스트의 질문은 가족에게 표현하는 경험에 집중한다. 넓은 서비스 대상 전체의 요구를 검증한 것으로 쓰지 않는다.

**문제 확인 결과: [실제 서면 응답·어머니 인터뷰 뒤 입력]** 20~30대 성인 후보 3명에게 구글폼 서면 응답을 한 번씩 받고, 어머니 한 명을 직접 인터뷰하기로 했다. 어머니는 아이디어 출발 경험의 당사자다. 실제 응답·허락·분석은 아직 확인되지 않았다.

## 대안과 사용자 선택

검토할 대안은 기존 전화·메시지를 활용하기, 표현 수단을 선택하게 하기, 질문·알림으로 계기를 주기다. 각 대안의 예상 도움과 반례는 [비교표](19_PLAN_남은작업_실행판.md#2단계-해결-방향-비교--선택-전-검토-자료)에 적었다. 실제 인터뷰 결과를 받기 전에는 어느 대안이 문제를 가장 잘 해결한다고 결론내리지 않는다.

사용자는 홈·작성·상세의 대표 화면에서 A안을 선택했다. 이후 손글씨·목소리·사진에 영상 수단을 추가하고, 데모에도 수정·삭제·앨범방 편집을 요청했다. 카드의 좋아요·댓글과 재생 표시, 홈·앨범방 정리도 사용자 요청과 AI 구현의 결과다. 최신 E6 화면은 별도 사용자 화면 확인이 남았다.

## 결과물과 구현 범위

[브라우저 데모](https://oneuldo-demo.vercel.app/demo)는 설치·가입 없이 한 개의 앨범방에서 작성 → 저장 → 열람·재생·반응 → 다시 보기를 체험하도록 만들었다. 데이터는 해당 브라우저에 저장되고, 실제 가족에게 전송되지 않는다. [홈 화면](인수인계/증거_2026-09-28_E6_홈과앨범방_정리/01_홈.png)과 [앨범방 화면](인수인계/증거_2026-09-28_E6_홈과앨범방_정리/02_앨범방.png)은 E6 당시 캡처다.

기존 Supabase 연동 앱의 새 DB 구조·추억 영상·나만 보기 공개·편집은 로컬에서 구현·검사했다. 데모와 기존 앱을 하나의 운영 서비스 결과로 합치지 않는다. 원격 DB 적용과 기존 앱 배포는 사용자 결정으로 보류 중이다.

## 확인한 것과 확인하지 못한 것

- E6 당시 데모 배포본 자동 시나리오 37/37 통과. 이번 정리 작업에서 공개 데모 주소의 HTTP 200 응답을 확인했다. HTTP 응답은 화면 조작 성공을 뜻하지 않는다.
- 앱은 E3 당시 로컬 DB 합성 검사 127/127, 로컬 앱 브라우저 화면 검사 13/13 통과. 실제 원격 DB·실기기·가입 흐름은 이 수치에 포함되지 않는다.
- 실제 휴대전화의 마이크·카메라·터치·글자 확대, 성인 3명의 문제 확인 응답, 어머니 인터뷰, 5명의 사용성 테스트와 설문은 **미확인 또는 `NOT_RUN`**이다.

**사용 후 자기 보고: [실제 참가자 응답 뒤 입력]** 직접 관찰 기록이 없다면 과업 완료·무도움 완료율을 쓰지 않는다.

**개선과 재확인: [반복해 보고된 막힘을 재현하고 사용자 우선순위 결정 후 입력]**

## 역할과 한계

사용자: 아이디어·기획 의도의 출발점, 대상 확장, 대표 시안 A 선택, 주요 데모 기능·명칭·원격 보류 결정. AI(Codex·Claude): 조사안 초안·비교 정리, 코드와 화면 구현, 기술 검사·기록. 팀원: 개발 과정에서 함께 논의했다는 사용자 진술까지 확인됨. 사용자는 “대부분 내가 한거”라고 추가로 밝혔지만, 팀원별 세부 역할을 그 말만으로 나누지 않는다. 현재는 확인된 역할만 적는 방식으로 진행한다.

현재 자율 체험 설문으로 첫 표현의 사용성·부담에 관한 **참가자 인식**을 들을 수 있다. 실제 과업 수행, 가족의 반응·관계 개선·지속 사용 효과를 관찰했다고 주장할 수 없다. 문제 경험이 없거나 기존 연락 방법이 더 나았던 반례도 결과에 함께 기록한다.
