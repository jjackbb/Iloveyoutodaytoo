# 사용성 테스트용 구글 설문 초안 — 발송 전 검토

문제 경험을 묻는 [1단계 설문 프롬프트](18_공동작성_인터뷰안_기반_구글폼_프롬프트.md)와 목적이 다르다. 이 초안은 데모를 사용한 뒤의 **자기 보고**를 받기 위한 문항 제안이다. 사용자는 **세 과업이 끝난 뒤 한 번** 받는 방식을 선택했다. 아래 7문항의 정확한 문구는 검토용이다. 실제 폼 생성·발송·응답은 `NOT_RUN`이다.

## 첫 화면 안내 초안

“오늘도 사랑해 데모를 사용한 경험을 묻습니다. 답하지 않기 어려운 질문은 건너뛸 수 있습니다. 이름·연락처·가족 실명·사적인 내용·사진·음성은 적지 말아 주세요. 설문 답변은 실제 화면 조작을 관찰한 결과와 구분해 비식별로 정리합니다.”

내부 기획용 비식별 요약 동의와 포트폴리오에서 비식별 요약 사용 동의를 분리한다. 직접 인용·화면 녹화·녹음은 별도 허락 없이 사용하지 않는다. 폼 설정은 이메일 자동 수집·로그인 요구·응답 요약 공개를 끈 상태인지 실제 생성 후 확인한다.

## 문항 제안

| 순서 | 질문 초안 | 형태·해석 한계 |
|---|---|---|
| 1 | 어떤 기기로 체험하셨나요? | 휴대전화/컴퓨터/기타. 모델·브라우저는 알면 선택 기입. |
| 2 | 데모에서 직접 해 본 것은 무엇인가요? | 작성, 예시 열람·재생, 좋아요·댓글, 다시 보기, 아무것도 못 함, 기타. **자기 보고**이며 완료 판정이 아님. |
| 3 | 하려던 일을 하면서 멈추거나 도움을 받은 곳이 있었다면, 그때 무엇을 하려 했나요? | 자유 응답. 없었다면 ‘없음’ 가능. 관찰 기록과 대조. |
| 4 | 가장 쉬웠던 부분과 이유는 무엇인가요? | 선택 자유 응답. 일반적인 호감 점수로 바꾸지 않음. |
| 5 | 가장 부담스럽거나 헷갈린 부분과 이유는 무엇인가요? | 선택 자유 응답. 사적인 글 내용을 받지 않음. |
| 6 | 평소 전화·메시지 등과 비교해 이 데모를 쓰고 싶은 상황, 쓰지 않을 상황이 있나요? | 선택 자유 응답. 구체적 상황과 반례를 함께 받음. |
| 7 | 화면을 써 본 뒤 생각이 달라진 점이나 빠진 의견이 있나요? | 선택 자유 응답. |

## 운영 전 체크

참가자가 실제로 화면을 사용했는지 확인하는 방식, 과업별 완료 조건, 진행자가 도움을 주는 시점을 정해야 한다. 사용자는 참여자 겹침을 허용하고 기존 노출·학습 효과를 남기기로 했다. 구글폼과 설문지의 구분·인원은 사용자 뜻을 확인해야 한다. 원격 화면 공유 또는 대면 관찰을 택하더라도 관찰 불가 구간은 그대로 표시한다. 폼을 만들더라도 사용자 검토 전에는 발송하지 않는다.
