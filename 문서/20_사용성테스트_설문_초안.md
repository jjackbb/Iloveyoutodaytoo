# 데모 후기 설문 7문항 — 데모 내부 입력·복사 전달

문제 경험을 묻는 [1단계 설문 프롬프트](18_공동작성_인터뷰안_기반_구글폼_프롬프트.md)와 목적이 다르다. 사용자는 앞서 사용성 구글폼을 생성했다고 밝혔지만, 이후 **데모 체험 화면 밖의 버튼에서 내부 설문으로 이동해 답변을 복사·직접 전달**하는 방식으로 바꿨다. 아래 7문항과 T1~T3은 이전에 선택한 문안을 유지한다. 실제 조작을 보거나 녹화하지 않으므로 전달받은 답은 **자기 보고**다. [구글폼 구성안](24_사용성테스트_구글폼_구성안.md)은 이전 방식의 기록이고 [현재 진행안](25_데모내_후기설문_복사전달_진행안.md)이 우선한다.

## 현재 화면 안내

데모 설문 첫 화면은 건너뛸 수 있는 질문, 민감한 내용 입력 자제, **복사 후 대화방에 직접 보내야 전달된다**는 점을 안내한다. 실제 화면 조작을 직접 확인하지 않으므로 답변은 자기 보고로 정리한다.

내부 기획용 비식별 요약 동의와 포트폴리오에서 비식별 요약 사용 동의를 분리한다. 직접 인용·화면 녹화·녹음은 별도 허락 없이 사용하지 않는다. 데모 내부 설문은 서버에 답을 보내거나 브라우저 저장소에 남기지 않는다. 참가자가 선택한 대화방으로 보내면 그 대화방의 발신자 정보는 수신자에게 보일 수 있음을 안내한다.

## 문항 제안

| 순서 | 질문 초안 | 형태·해석 한계 |
|---|---|---|
| 1 | 어떤 기기로 체험하셨나요? | 휴대전화/컴퓨터/기타. 모델·브라우저는 알면 선택 기입. |
| 2 | 데모에서 직접 해 본 것은 무엇인가요? | 작성, 예시 열람·재생, 좋아요·댓글, 다시 보기, 아무것도 못 함, 기타. **자기 보고**이며 완료 판정이 아님. |
| 3 | 하려던 일을 하면서 멈추거나 도움을 받은 곳이 있었다면, 그때 무엇을 하려 했나요? | 자유 응답. 없었다면 ‘없음’ 가능. 구체적인 화면 행동은 검증되지 않은 자기 보고. |
| 4 | 가장 쉬웠던 부분과 이유는 무엇인가요? | 선택 자유 응답. 일반적인 호감 점수로 바꾸지 않음. |
| 5 | 가장 부담스럽거나 헷갈린 부분과 이유는 무엇인가요? | 선택 자유 응답. 사적인 글 내용을 받지 않음. |
| 6 | 평소 전화·메시지 등과 비교해 이 데모를 쓰고 싶은 상황, 쓰지 않을 상황이 있나요? | 선택 자유 응답. 구체적 상황과 반례를 함께 받음. |
| 7 | 화면을 써 본 뒤 생각이 달라진 점이나 빠진 의견이 있나요? | 선택 자유 응답. |

## 운영 전 체크

성인 참가자에게 [배포 링크와 T1~T3](25_데모내_후기설문_복사전달_진행안.md)을 함께 전달하고, 자율 체험 뒤 데모 내부 설문에 답해 복사·직접 보내도록 한다. 사용자는 참여자 겹침을 허용하고 이전 데모 노출·학습 효과를 남기기로 했다. 이번 완료 목표는 성인 5명에게서 **실제로 받은** 답변이다. 설문 답만으로 무도움 완료율이나 실제 조작 순서를 계산하지 않는다. 참가자에게 보내는 일은 아직 하지 않았다.
