# 사용성 테스트용 구글 설문 문항 — 사용자 선택 반영

문제 경험을 묻는 [1단계 설문 프롬프트](18_공동작성_인터뷰안_기반_구글폼_프롬프트.md)와 목적이 다르다. 사용자는 데모 배포 주소를 전달해 참가자가 스스로 둘러본 뒤 **구글 설문폼으로 한 번** 답을 받기로 했다. 아래 7문항과 T1~T3의 문장·완료 조건을 사용하기로 선택했다. 실제 조작을 보거나 녹화하지 않는 방식이므로 응답은 **자기 보고**이며, 과업 완료를 직접 관찰한 결과가 아니다. 실제 폼 생성·발송·응답은 `NOT_RUN`이다. 복사용 구성은 [24번 문서](24_사용성테스트_구글폼_구성안.md)에 있다.

## 첫 화면 안내 초안

“오늘도 사랑해 데모를 사용한 경험을 묻습니다. 답하기 불편한 질문은 건너뛸 수 있습니다. 이름·연락처·가족 실명·사적인 내용·사진·음성은 적지 말아 주세요. 화면 조작을 직접 확인하지 않으므로 답변은 체험에 관한 자기 보고로 정리합니다.”

내부 기획용 비식별 요약 동의와 포트폴리오에서 비식별 요약 사용 동의를 분리한다. 직접 인용·화면 녹화·녹음은 별도 허락 없이 사용하지 않는다. 폼 설정은 이메일 자동 수집·로그인 요구·응답 요약 공개를 끈 상태인지 실제 생성 후 확인한다.

## 문항 제안

| 순서 | 질문 초안 | 형태·해석 한계 |
|---|---|---|
| 1 | 어떤 기기로 체험하셨나요? | 휴대전화/컴퓨터/기타. 모델·브라우저는 알면 선택 기입. |
| 2 | 데모에서 직접 해 본 것은 무엇인가요? | 작성, 예시 열람·재생, 좋아요·댓글, 다시 보기, 아무것도 못 함, 기타. **자기 보고**이며 완료 판정이 아님. |
| 3 | 하려던 일을 하면서 멈추거나 도움을 받은 곳이 있었다면, 그때 무엇을 하려 했나요? | 자유 응답. 없었다면 ‘없음’ 가능. 구체적인 화면 행동은 검증되지 않은 자기 보고. |
| 4 | 가장 쉬웠던 부분과 이유는 무엇인가요? | 선택 자유 응답. 일반적인 호감 점수로 바꾸지 않음. |
| 5 | 가장 부담스럽거나 헷갈린 부분과 이유는 무엇인가요? | 선택 자유 응답. 사적인 글 내용을 받지 않음. |
| 6 | 평소 전화·메시지 등과 비교해 이 데모를 쓰고 싶은 상황, 쓰지 않을 상황이 있나요? | 선택 자유 응답. 구체적 상황과 반례를 함께 받음. |
| 7 | 화면을 써 본 뒤 생각이 달라진 점이나 빠진 의견이 있나요? | 선택 자유 응답. |

## 운영 전 체크

배포 링크를 전달하고 참가자가 자율 체험한 뒤 구글폼에 응답한다. 사용자는 참여자 겹침을 허용하고 이전 데모 노출·학습 효과를 남기기로 했다. T1~T3 문장을 링크와 함께 보낼지, 자유롭게 둘러본 뒤 설문에서만 물을지는 아직 확인해야 한다. 설문 응답만으로 무도움 완료율이나 실제 조작 순서를 계산하지 않는다. 실제 폼 설정과 데모 링크가 열리는지는 발송 전 확인한다. 참가자에게 보내는 일은 아직 하지 않았다.
