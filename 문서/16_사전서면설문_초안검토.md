# 20~30대 사전 서면 조사 — 사용자 공유 폼 문안 검토

기준일: 2026-09-28. 사용자가 Google Form에 표시된 제목·안내·문항을 대화에 붙여 주어 **문안만** 검토했다. 폼 편집 설정, 실제 분기·필수 여부, 이메일 수집, 접근 권한, 전송·응답은 확인하지 않았다. 사용자가 공유한 계정 주소와 응답 링크는 이 문서에 복제하지 않는다. 이것은 실제 참여자 답변이나 테스트 결과가 아니다.

## 잘 맞는 점

- 평소 표현 수단 → 최근 실제 장면 → 표현한 방법의 충분함 또는 미표현 이유 → 편했던 반대 사례 → 추가 경험의 큰 흐름이 [공동 작성 질문안](09_사전인터뷰_전체흐름_공동작성.md)과 대체로 맞는다.
- 최근 기억나는 장면이 없다는 선택지와 편했던 순간의 ‘해당 없음’을 둬, 문제 경험을 억지로 만들지 않게 했다.
- 가족의 반응이 좋았는지나 서비스가 필요한지부터 묻지 않고, 본인이 당시 실제로 한 일을 묻는다.
- 포트폴리오에는 직접 인용이 아닌 요약을 쓰려는 범위를 안내했다.

| 우선 | 문안에서 확인한 점 | 권장 수정과 이유 |
|---|---|---|
| 1 | 최근 장면 선택 뒤에 ‘실제로 표현한 경우’와 ‘전하지 않은 경우’의 상세 질문이 모두 나열돼 있다. 붙여 준 텍스트만으로 실제 분기·필수 설정은 알 수 없다. | 최근 장면 선택에 따라 **표현함 → 상황·행동·충분함**, **전하지 않음 → 상황·그 뒤 행동·이유**, **기억나는 장면 없음 → 공통 반대 사례**로 이동하게 한다. 분기가 없으면 각 상세 질문을 선택으로 두고 해당자만 답하도록 문구를 명시한다. 무관한 답변을 강요하지 않기 위해서다. |

| 2 | 사용자가 선택한 개인적 아이디어 출발점 소개가 현재 붙여 준 문안에는 없다. | 계속 소개할 계획이라면 **모든 경험 답변을 마친 뒤** 마지막 설명 또는 제출 완료 안내에 짧게 둔다. 소개 뒤에 공감·서비스 필요 여부를 묻지 않는다. 어머니 직접 인터뷰에는 이 소개를 그대로 읽지 않는다. |

전체 문항의 주제는 충분하다. 수정의 핵심은 질문을 더 늘리는 일이 아니라 **응답자에게 맞는 갈래만 보이게 하고, 한 장면에서 실제로 한 행동을 놓치지 않는 것**이다. 문항별 필수 여부와 분기, 응답 확인 화면은 폼 편집 화면에서 따로 점검해야 한다. 실제 설정 확인 전에는 위 문제를 ‘현재 폼의 동작 오류’라고 단정하지 않는다.
