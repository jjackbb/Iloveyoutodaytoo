# 구글 스티치 — 화면별 프롬프트 (2026-09-28)

현재 데모(https://oneuldo-demo.vercel.app/demo)의 화면을 그대로 옮긴 프롬프트다. 스티치로 **다른 디자인 방향을 뽑아 보고**, 결과를 보고 Claude Design 캔버스에서 다듬을 예정이다(사용자 계획).

## 쓰는 법

1. 스티치(stitch.withgoogle.com)에서 새 프로젝트를 만들고, 같은 폴더의 **[DESIGN.md](DESIGN.md)** 를 디자인 시스템으로 가져온다. 외부 가이드 기준 메뉴는 "Settings → Design System → Import DESIGN.md"이며, 실제 메뉴 이름은 다를 수 있다. 가져오기가 안 되면 첫 프롬프트 앞에 DESIGN.md 내용을 붙여 넣는다.
2. **1번(홈)부터 차례로** 같은 프로젝트 안에서 만든다 — 앞 화면과 톤이 이어진다.
3. 각 프롬프트는 영어(스티치가 더 잘 알아듣는다), 화면 글자는 실제 한국어 문구다. 바꾸고 싶은 점은 끝에 한 줄로 덧붙이면 된다(예: "Try a denser layout").
4. 고정 결정(4:3 앨범 표지, 왼쪽 아래 이름표 29px·좌우 9px, 숫자 배지, 번트 오렌지 한 색)은 DESIGN.md에 들어 있다. 스티치가 바꿔 오면 그 부분은 참고만 한다.

공통 머리말(모든 프롬프트 앞에 자동으로 붙이거나 첫 화면에만 붙인다):

```
Mobile app screen, 390x844, Korean UI, font Pretendard. Follow the attached DESIGN.md strictly (neutral canvas, single burnt-orange accent #BF3F0D used only as points, flat cards with 1px hairline, 16px radius, 4:3 media). App name "오늘도 사랑해": a private album app for leaving small expressions of love to someone precious. Calm, warm, quiet — like a paper album, not a social network. No status bar mockups, no emoji, no gradients.
```
