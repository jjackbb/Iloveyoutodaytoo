## 2026-09-06 — 앨범방 카드

캔버스: https://claude.ai/code/artifact/ae8f84d1-4d66-42cf-a3dc-67746d5b6cdd (페이지 "앨범방 카드 · 확정")
작업 파일: `design/canvas/components/Main.dc.html`

| | 결정 | 왜 |
| :--- | :--- | :--- |
| 기본 톤 | **토스식** — 플랫, 그림자 없음, 1px 테두리 `#e5e8eb`, 반지름 **16px** | 사용자 선택. 가장 가볍다 |
| 사진 | **4:3, 카드 전체** | "커버사진을 넣은 이상 잘 보여야 한다." 아래 정보 띠를 없앴다 |
| 하트 | 사진 **우상단**, 흰 획만(원 없음), 옅은 drop-shadow. 즐겨찾기하면 **분홍 `#ff5a7a`** 채움 | 원을 두면 사진 위가 붐빈다 |
| 이름 | 사진 **좌하단 모서리에 딱 붙은 흰 칸** — 높이 **29**, 좌우 **9 대칭**, 안쪽(우상단) 모서리 **10px**, 글자 15/600 세로 가운데 + **1px 광학 보정** | 흰 글자+어두움은 민무늬에서만 읽혔다. 일상 사진 위에선 묻힌다. 띄운 알약·사각은 "괜히 떠 있어 더 보기 싫다"(사용자) |
| 새 마음 | **글자의 우상단**에 **강조색 점 6px**(`top:4 right:3`) — 숫자 없음. 없으면 점도 없음 | 숫자는 커지면 숙제가 된다(북극성 "즐거운 일과"). 점은 있다는 것만 말한다 |
| 아바타 | **없음** | 뱃지와 시선을 나눠 가진다. 누가 있는지는 방에 들어가면 보인다 |
| 통계 줄 | **없음** ("멤버 3명 · 게시물 12개" 폐기) | 감정 앱이 대시보드처럼 읽혔다 |

**색** — 점은 브랜드 강조색 `#BF3F0D`(로고 세션 확정). 하트 활성은 `#ff5a7a` — **임시**. 둘 다 의미색(알림·좋아요)이라 강조색과
따로 정해도 되지만, 지금 앱에 색이 없어 **첫 색들**이 된다. 로고 색이 나오면 옆에 놓고 다시 본다.

**이 결정이 답한 것** — 모서리·여백 규격 3안(A/B/C) 캔버스는 사실상 닫혔다.
토스식을 고른 순간 기하가 토스 것을 따른다: 카드 16 / 버튼 xl 16·l 14·m 10·s 8 /
작은 면 4~6. 여백은 4·8·16·24.

**남은 것** — 버튼 · 입력칸 · 칩 · 안쪽 면. 같은 캔버스 뒤 페이지에 3안씩 있다.

### 2026-09-07 보충 — 칸 여백을 손으로 맞추다 배운 것

캔버스에서 직접 칸을 줄이면 **… 이 생겼다.** 원인은 두 가지가 겹친 것:

1. 글자를 **`left: -5.42px` 로 밀어** 왼쪽 여백을 줄였다 — 보이기만 옮겼을 뿐
   **레이아웃 여백은 14px 그대로**라, 오른쪽을 줄이면 글자가 들어갈 자리가 모자란다.
2. 칸에 **`width: 128px` 가 박혀 있었다**(끌다가 들어간 값). 글자 폭보다 좁아지는 순간 잘린다.

→ **시각 밀기를 진짜 여백으로 옮기고**(`padding: 0 9px`) **고정폭을 뺐다.**
좌우 9px 대칭, `…` 없음. 세 이름 길이(짧음·보통·김) 모두 브라우저에서 확인했다.

**점의 자리** — `right: 3px`. 칸 폭 = 글자 + 18 이므로 점은 **항상 글자가 끝나는 지점**에
앉는다(글자 길이와 무관). 고정폭 안에서는 글자가 `W-9` 에서 잘리고 점이 거기서 시작해
**겹치지 않는다.** 절대 위치라 점이 생겨도 칸 폭은 그대로다.

### 2026-09-08 — 다른 앱 참고 4·5안 (검증 상태가 다름)

같은 "새 마음이 있다" 신호를 토스·당근마켓이면 어떻게 표현할지 참고로 추가했다.
**둘의 검증 근거가 다르다 — 섞어서 인용하지 말 것.**

| | 표현 | 근거 |
| :--- | :--- | :--- |
| ④ 토스식 | 이름 위에 텍스트 뱃지 **"NEW"**(파랑 `#3182f6` 채움) | ✅ **근거 있음** — `toss_DESIGN.md` §4 TDS Mobile Badge: "fill or weak; semantic colors" "descriptive rather than interactive" |
| ⑤ 당근마켓식 | 이름표 **우상단 모서리에 걸친** 숫자 원형 뱃지(흰 테두리) | ⚠️ **미검증** — 이 세션에서 당근마켓 공식 문서나 화면을 확인하지 못했다. 색(`#ff8a3d`)·크기·위치 전부 "숫자 원형 뱃지"라는 일반 관례를 재현한 것이지 실측이 아니다 |

**채택하지 않았다.** 우리가 이미 고른 점(dot)은 이 둘 사이 어딘가다 — 토스보다 조용하고
(글자가 없다) 당근보다 정보가 적다(숫자가 없다). 숫자를 넣을수록 "몇 개 밀렸는지"는
보이지만, 숫자가 늘수록 숙제로 읽힐 위험도 커진다(§1 북극성 "즐거운 일과" 참고).
