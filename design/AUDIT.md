## 🟡 모서리 — 토큰이 있는데 절반쯤만 쓴다

### 이미 있는 토큰 (`globals.css`)

```
--radius-card:       22px
--radius-button:     17px
--radius-inner:      14px
--radius-inner-sm:   11px
--radius-chip:      100px
```

### 실제 사용

| 방식 | 횟수 |
| :--- | ---: |
| `rounded-full` | 63 |
| `rounded-inner` | 56 |
| `rounded-card` | 21 |
| **`rounded-[14px]`** | **22** |
| **`rounded-[8px]`** | **17** |
| `rounded-[26px]` | 2 |
| `rounded-[10px]` | 2 |
| `rounded-[11px]` | 1 |
| `rounded-[20px]` | 1 |

**두 가지 문제가 보인다.**

1. **`rounded-[14px]` 22곳은 `rounded-inner`(=14px)와 값이 똑같다.**
   같은 것을 두 방법으로 쓰고 있다 — 78곳 중 22곳이 하드코딩. 기계적으로 바꿀 수 있다.
2. **`rounded-[8px]` 17곳은 대응하는 토큰이 없다.**
   가장 작은 토큰이 `inner-sm`(11px)이라 8px이 갈 곳이 없었다.
   → **8px 토큰을 새로 만들지, 11px로 흡수할지** 정해야 한다.
   `rounded-[11px]` 이 1곳뿐인 걸 보면 11px은 거의 안 쓰인다 — **11px을 8px로 내리는 안**도 있다.

`26px` · `20px` · `10px` 은 각 1~2곳이라 가장 가까운 토큰으로 흡수하면 된다.
