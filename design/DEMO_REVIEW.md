# 브라우저 데모 UX/UI 검토 — 2026-09-22

> **2026-09-25 사용자 확인:** 소개 화면은 가족방과 손글씨·목소리·사진 세 수단을 포괄하는 방향으로 설명한다. 기존 ‘목소리로 남기는 비밀 감정 사서함’ 문구는 현재 화면의 과거 표현이며 이번 데모의 소개 기준으로 사용하지 않는다. 실제 한 문장과 배치는 대표 화면 시안에서 검토한다. AI 문구 초안: “우리 가족방에 손글씨, 목소리, 사진으로 마음을 남겨요.” 사용자 최종 문구 승인이나 코드 반영은 아직이다.

## 사용자와 확인한 것

- 브라우저 데모 중심, 안드로이드 앱은 보조 자료. Supabase 연결은 보류.
- 화면은 모니터링하며 함께 다듬는다. 중요한 UX 선택을 AI가 대신 확정하지 않는다.
- 작성은 **먼저 손글씨·목소리·사진 중 하나를 고르고, 나중에 다른 수단도 추가**한다(이번 질문에 사용자 선택).
- 수단을 고른 뒤에는 **작은 전환 탭으로 줄여 작성 공간을 확보**한다(화면 확인 후 추가 질문에 사용자 선택).
- 기존에 확정된 로고·번트색·Pretendard·플랫한 카드·4:3 사진·좌하단 이름표를 재사용한다.

## 이번 구현 방향

- 주인공은 남겨진 마음과 기록. 거대한 홍보 문구·새 브랜드·불필요한 장식을 추가하지 않는다.
- 바탕 #f7f8fa, 내용 면 #ffffff, 글자 #222222, 보조 #6a6a6a, 강조 #bf3f0d, 선 #e5e8eb.
- 기본 글자 16px, 주요 행동 16~18px, 제목 22~24px. 본문과 버튼의 좌우 시작점을 맞춘다.
- 확정 카드의 16px 모서리와 4:3 비율을 데모에 적용. 다른 앱 화면의 토큰은 일괄 변경하지 않는다.
- 역할 전환·초기화는 체험 도구로 표시. 제품 기능과 가상 자료를 구분한다.
- 작성 시 수단 전환으로 이미 담은 기록을 잃지 않게 한다. 저장 실패는 화면에 알리고 입력을 보존한다.

## 구현 뒤 사용자와 볼 것

1. 첫 화면에서 가족방과 새 마음이 잘 구별되는지.
2. 작성 수단 선택의 크기·배치가 부담스럽지 않은지.
3. 강조색·여백·카드가 지나치게 무겁거나 밋밋하지 않은지.

현재 디자인은 기존 확정안의 데모 적용과 새 작성 흐름의 1차 검토본이다. 사용자 확인 전 최종 디자인으로 표시하지 않는다.
