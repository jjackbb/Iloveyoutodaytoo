# 1단계 — 토큰 대조표

> 2026-08-08 / 원본: `PRD/references/prototype-mingyu.html` 1~1,991줄 (`<style>`)
> 대상: `src/app/globals.css`
> **색은 대조 대상이 아니다** — 현재 값 고정 (WCAG AA 검증 통과, `05_REDESIGN_PLAN.md` §1)

## 요약

프로토타입에서 **여백·모서리·그림자·전환**을 뽑아 현재 토큰과 맞춰봤다.
**모서리와 그림자는 이미 일치한다** — 지난 작업에서 가져왔다.
충돌은 **글자 크기 체계 하나**이고, **새로 필요한 토큰이 5개** 있다.

---

## A. 충돌 — 결정이 필요하다

### A-1. 글자 크기 체계 (유일한 진짜 충돌)

프로토타입은 **13.5px가 기준**이고, 우리는 **17px가 기준**이다. 시니어 사용자 때문에
의도적으로 키운 값이라 `05_REDESIGN_PLAN.md` §5 "손대지 않는 것"에 들어가 있다.

프로토타입 실측 분포 (많이 쓰인 순):

| 프로토타입 | 쓰인 곳 | 17px 기준으로 옮기면 |
|---|---|---|
| 13.5px | 본문·세그먼트 버튼 (16회) | `text-base` 17px |
| 13px | 보조 문구 (15회) | `text-[0.94rem]` 16px |
| 12px | 캡션 (14회) | `text-sm` 14.9px |
| 15.5px | 주요 버튼 글자 | `text-[1.12rem]` 19px |
| 19px | 앱바 브랜드명 | `text-[1.35rem]` 23px |
| 17px | 화면 제목 | `text-[1.24rem]` 21px |

**제안: 비율만 가져오고 절대값은 버린다.** 프로토타입의 13.5px를 그대로 쓰면
시니어에게 너무 작고, PRD "절대 하지 마"(작은 폰트 금지)에 걸린다.

> 이 항목은 사실상 이미 정해진 결정(§5)이라, 반대 의견이 없으면 그대로 갑니다.

### A-2. 터치 목표 — 아이콘 버튼

| | 프로토타입 | 현재 |
|---|---|---|
| `.iconbtn` | **40px** | `min-height: 44px` 강제 |

`globals.css`에 이미 "보이는 크기는 그대로 두고 여기만 44px로 지킨다"고 적혀 있다.
즉 **보이는 원은 40px, 실제 누를 수 있는 영역은 44px**. 그대로 유지한다.

## C. 새로 필요한 토큰 — 지금 없어서 화면마다 숫자를 박게 된다

프로토타입 실측값이고, 화면 3개 이상에서 반복된다. 토큰으로 두지 않으면
화면마다 손으로 적게 되고 그게 나중에 어긋난다.

| 제안 토큰 | 값 | 근거 (프로토타입 실측) |
|---|---|---|
| `--radius-inner-sm` | `11px` | 세그먼트 안쪽 칸 (`.seg button`). 14px 트랙 안에 들어가려면 더 작아야 한다 |
| `--spacing-screen-x` | `20px` | `.appbar` `.body` `.foot-btn` 좌우 여백이 전부 20px. 화면 3단의 세로줄을 맞추는 값 |
| `--spacing-body-bottom` | `22px` | `.body`와 `.foot-btn` 아래 여백 |
| `--spacing-card-gap` | `14px` | 카드 사이 간격 (`margin-top:14px`, 6회로 최다) |
| `--shadow-chip` | `0 4px 12px -4px rgba(60,20,35,.25)` | `.chip-inv` 등 떠 있는 작은 요소 |

### 레이아웃 3단 실측 (부품 만들 때 쓸 값)

```
.appbar     padding: 6px 20px 12px    (고정)
.body       padding: 2px 20px 22px    (스크롤)
.action-bar padding: 11px 18px        (고정, 위쪽 1px 선)
.foot-btn   padding: 14px 20px 22px   (고정, 선 없음)
```

`action-bar`(18px)만 좌우 여백이 다르다 — 프로토타입의 실수로 보이지만,
버튼이 꽉 차는 바라서 눈에 띄지 않는다. **20px으로 통일할 것을 제안한다.**

## D. 가져오지 않는 것

| 항목 | 프로토타입 | 이유 |
|---|---|---|
| 강조색 | `#FF4E74` | 흰 글자 대비 3.18:1 — **WCAG AA 미달** |
| 보조 회색 | `#A9A6AB` | 2.26:1 — 미달 |
| 기준 글자 | 13.5px | 시니어에게 너무 작다 |
| 기기 프레임 | `.device` `.notch` `.statusbar` | 목업용 아이폰 껍데기. 실제 앱엔 없다 |
| 화면 전환 | `.page` `opacity/visibility` | **잔여데이터의 원인.** 라우팅은 Next.js가 한다 |
